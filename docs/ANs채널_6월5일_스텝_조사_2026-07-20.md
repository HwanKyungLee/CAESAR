## 1. R 시계열 에러바 (ch1 넓음 / ch2 좁음)

**질문**: R time-series에서 ch1(파랑) 점선 폭이 ch2(주황)보다 훨씬 넓다. 문제인가?

**확인**: [`gui/ui_dialogs_r.py:836`](../gui/ui_dialogs_r.py) 의 에러바는 `r_std`,
이는 [`tools/r_trend_monitor.py:397`](../tools/r_trend_monitor.py) 에서

```python
"r_std": float(np.std(r_fit)),   # r_fit = 채널 핏 윈도우 안의 R(λ) 곡선
```

즉 **한 파일의 R(λ)를 파장 방향으로 낸 표준편차**다. 시간 반복성도, 측정 노이즈도 아니다.

**판정: 정상.**
- ch1 미러 코팅의 반사율 곡선이 자기 핏 윈도우 안에서 더 기울어져 있을 뿐
- 폭이 3주 내내 일정 (오염·퍼지 불량이면 시간에 따라 변해야 함)
- 핏에 들어가는 건 스칼라 평균이 아니라 R(λ) 곡선 자체 → 기울기가 커도 편향 아님

`cold (435,480)`, `hot_pns (430,465)`, `hot_ans (435,470)`

## 3. 전기간 채널 정체성 판별 — CH1 = ANs 재확정

**스크립트**: `scratchpad/ans_channel_id.py`
**표본**: 5/18~7/9, 시간정합 46,425 쌍
**분석용 필터(비파괴)**: Status OK / 정착 첫 3스캔 제외 / 건조(주입) 스캔 제외

### 방법

d = NO₂(CH1) − NO₂(CH2) 를 일별 Theil-Sen 회귀로 분해:

```
d = a + b·C        (C = 두 채널 평균 농도)
  a : 덧셈 성분 → 진짜 ANs 신호 + 영점차
  b : 비례 성분 → R/L_eff 채널 간 스케일 불일치
```

진짜 300 °C 셀이라면 **a > 0**이어야 한다 (더 뜨거운 셀이 더 분해 → 더 읽음).

### 결과

| 구간 | slope b (비례) | intercept a (덧셈) |
|---|---|---|
| 5/17–5/31 | +0.102 | +0.068 |
| 6/01–6/15 | −0.054 | +0.170 |
| 6/16–6/30 | −0.004 | +0.072 |
| 7/01–7/08 | −0.043 | +0.047 |
| **전체** | **−0.003** | **+0.084** |

- **덧셈 성분 a > 0 인 날: 43/52일 = 83 %**
- 모델-프리 교차검증 (저농도 C<1 ppb, 회귀 없이): 5월 +0.14 / 6월 +0.14 / 7월 +0.03 — **전부 양수**

**→ CH1 = ANs(300 °C), CH2 = PNs(180 °C) 확정. ANs = CH1 − CH2.**

7월에 겉보기 CH2 > CH1로 뒤집힌 건 a가 작아지고(+0.03) b(−4 %)가 덮은 것 — 채널 정체성과 무관.

### 부수: 일주기는 애매

비례 성분·일별 median 제거 후 d_anom 일주기는 **bimodal**(03–07 h, 14–16 h 피크).
깨끗한 오후 광화학 피크가 아니다 → **ANs가 real인지 thermal artifact인지는 여전히 미해결.**

## 4. 6/5 스텝의 원인 — 필터 종류가 아니라 얼라인먼트

**스크립트**: `scratchpad/filter_swap_trace.py`, `filter_epochs.py`, `slope_vs_signal.py`

### 4-1. 필드로그 (사용자 제공)

- 6/4~6/5 밤: Dark 측정
- 6/5: ROI2(= ANs = CH1) 밴드패스 필터 **새것 테스트 → 당일 원래 필터로 원복**
- 6/14: **LED2 세기 낮춤**

### 4-2. 하드웨어 상태 에폭

CH1/CH2 신호비(`_signal_mean`)로 본 상태 구분:

| 에폭 | 신호비 CH1/CH2 | 스케일 슬로프 b |
|---|---|---|
| ~6/4 | 1.1 – 1.3 | **+10 %** |
| 6/5 – 6/13 | 0.65 – 0.88 | **−5 ~ −13 %** |
| 6/14 ~ (LED2 조절 후) | ~0.95 | **~0 %** ← 가장 건강 |

**핵심: 원래 필터로 되돌렸는데도 5월 상태로 복귀하지 않았다.**
→ 원인은 "어떤 필터냐"가 아니라 **필터를 뺐다 끼우는 작업 자체가 바꾼 얼라인먼트**.

### 4-3. 스케일 오차가 광학 상태를 따라간다

일별 slope b vs 신호비 (52일):

- **Pearson r = +0.761 (p = 5.7e−11)**, Spearman ρ = +0.754
- Theil-Sen: `b ≈ +1.03 % + 0.288·ln(ratio)` → **ratio = 1일 때 b ≈ +1 %**
- 에폭 **내부** 상관은 null (각 ρ, p > 0.5)

→ "빛이 세면 농도가 커진다"는 직접 기전이 아니라, **각 하드웨어 개입이 얼라인먼트를
바꿨고 신호비는 그 상태의 마커**. 기전 후보: 미광 분율(핏에서 Stray Light Correction
**OFF** 상태), 검출기 비선형, 스펙트럼 모양 변화.

### 4-4. 5월이 오히려 이상 구간

필터 제거 후 b가 5월(+10 %)로 안 돌아가고 ~0이 됐다 → **5월 +10 %가 이상**.
5월은 실린더 만료·인젝션 불량으로 R(t) 보간이 많던 시기
(`injection-qc-tz-conclusions-2026-06` 참조).

**참고**: 절대 `_signal_mean`은 대기 에어로졸 소산에 지배돼 시간당 몇 배씩 출렁인다.
LED 스텝 직접 검출은 불가능 — **두 채널의 비율만이 하드웨어 상태를 본다.**

## 5. 교수님 제안 검증 — "핏레인지를 바꿔 드롭을 막자"

교수님 제안의 물리적 근거는 타당한 가설이었다: 간섭 밴드패스 필터는 tilt에 따라
통과대역이 이동하므로, 재장착으로 각도가 달라졌다면 핏 창을 조정할 정당한 이유가 된다.
**이를 두 단계로 직접 시험했다.**

### 5-1. 1단계 — Shift/RMS로 본 파장창 이동 여부

| 구간 | CH1(ANs) Shift | CH2(PNs) Shift |
|---|---|---|
| ~6/4 | −5.775 px | −1.438 px |
| 6/5–6/13 | −6.064 (**Δ −0.29**) | −1.728 (**Δ −0.29**) |
| 6/14~ | −5.488 (회복) | −1.379 (회복) |

**두 채널이 0.29 px씩 똑같이 밀렸다가 함께 돌아왔다 = 공통모드.**
필터는 CH1에만 있는데 CH2도 같이 움직였으므로 원인은 공유된 것(분광기 온도·파장보정).
CH1 Shift는 필터 작업 *전인* 6/1(−6.4)·6/3(−6.6)에 이미 그 범위 → 6/5에 깨끗한 스텝 없음.

핏 품질도 악화 없음: CH1 RMS 1.385 → 1.285 (e−9)로 **오히려 개선**, Chi2 ~1.10 안정.

### 5-2. 2단계 — 잔차 구조 비교

**스크립트**: `scratchpad/resid_epoch.py` → `resid_epoch.png`

프로덕션 재현 검증 완료 (ANs shift −6.25/−6.00 px, RMS 1.32~1.38e−9 — 실제 핏 파일과 일치).

> **재현 시 주의**: 프로덕션은 스캔 간 순차 전파로 shift(−6 px)에 도달한다. 고립 스캔을
> 핏하려면 (a) 넓은 격자탐색(−9~+3 px)으로 초기값을 잡고 (b) 시나리오의
> `NO2.sh_val` 한계 `[-2,2]`를 넓혀야 한다. 안 그러면 shift 0에 갇혀 RMS가 2배로 나온다.

4개 에폭(5월 / 6.1–4 / 6.6–12 / 6.15–22) 평균 잔차:

| 채널 | E2−E1 변화 / 노이즈 | 밴드 가장자리 \|z\|>3 비율 |
|---|---|---|
| ANs | **1.13배** | **0.0 %** |
| PNs (대조군) | 1.00배 | 0.0 % |

**네 에폭의 평균 잔차가 완전히 겹친다. 통과대역 이동 흔적 없음 = 고칠 창이 없다.**

### 5-3. 3단계 — 핏레인지를 실제로 바꿔서 재핏

**스크립트**: `scratchpad/range_test.py`
시간정합 동시 스캔쌍으로 d = NO₂(ANs) − NO₂(PNs) 계산.

| 핏레인지 | d(6/1–4) | d(6/6–12) | **6/5 스텝** |
|---|---|---|---|
| (a) 프로덕션 ANs 430–462 / PNs 444–471 | +0.491 | +0.022 | **−0.469** |
| (b) 공통창 둘 다 444.5–461.5 | +0.685 | +0.111 | **−0.574** |
| (c) 공통창 둘 다 446–460 | +0.398 | +0.107 | **−0.291** |

**어느 창에서도 스텝이 사라지지 않는다.** 물리적으로 가장 정당해 보였던 (b)안

| **21 h** (로그상 21:47 교체) | 0.904 | 60 |
| **22 h** | **1.014** ← 오히려 회복 | 60 |

**스텝은 13–15시에 일어났고, 21:47에는 오히려 0.83 → 1.01로 회복됐다.**
13시대 스캔 결손(60→47)도 그 시각의 작업 흔적.

### 7-3. 가설: 로그의 두 작업 시각이 뒤바뀌었다

첫 전달은 "22:47~22:04 Dark", 이후 "21:47~22:04 필터 교체"였다. 데이터는 그 반대를 가리킨다:

- **13~14시경: 필터 교체** → CH1 투과율 저하, 비율 1.2 → 0.78
- **21:47~22:04: Dark 측정 (+ 원래 필터로 원복)** → 비율 0.83 → 1.01 부분 회복

**→ 필드로그 원본에서 6/5의 두 작업 시각 확인 필요. 특히 13~14시대 기록.**

### 7-4. 정정된 초기 오류

초기 분석에서 "6/5 00시 스텝"이라고 기록했으나 이는 **저신호 스캔의 비율 폭주 탓**이었다.
신호 하위 20 % 컷 후 재분석한 13–15시가 맞다.
