- HK만으로 계산한 ch2/ch1 농도 스케일: **A0(~5/26) 1.1973 → 5/27부터 1.0332 (−15.9%)**.
- **그런데 실제 g는 5/27에 −1.3%만 움직였다.** 이유(대수적으로 유도, 관측과 일치):
  ```
  R 교정:  L_eff = τ_Ray/(σ_Ray·n_air)      ← n_air 들어감
  농도환산: x     = τ/(σ·L_eff·n_air)        ← n_air 또 들어감
  ⇒ n_air가 약분된다. T가 틀려도 농도는 (거의) 안 변한다.
  ```
- ⚠️ **따라서 5/28 ch2 R 계단(+14.5%)은 광학사건이 아니다** — HK T 변화가 R 계산(레일리 N)에 전파된 인공물. (세션 중 "미지의 사건"으로 잘못 보고했다가 철회함.)
- 🚨 **지뢰**: 현재 FitSet은 두 채널 `gas_temp: 0.0` → 오버라이드 **OFF** → 위 약분이 성립 → **지금이 맞다.**
  누군가 "실제 오븐온도를 넣어야지" 하고 ch1=180 / ch2=300을 켜면 약분이 깨지고
  **g가 (300+273)/(180+273) = 1.265배, 즉 26% 튄다.** 절대 켜지 말 것. 켤 거면 R 교정도 같은 온도로 다시 계산해야 한다.

## 2. ANs 결론 — ⛔ **§2-2 방법 폐기 (2026-08-01)**

### 시도 이력

| # | 방법 | 결과 | 판정 |
|---|---|---|---|
| 1 | 새벽 co-zero (일별 오프셋) | ANs ≈ 0 | 폐기 — 일별 오프셋이 일주기를 과하게 누름 |
| 2 | H₂O 내부추적자 `ANs = ch2/r − ch1` | ANs **+0.15** | 폐기 — 과보정(§2-1) |
| 3 | 곱셈/덧셈 분리 `ch2 = g·ch1 + a` | ANs = **−0.06 ± 0.08** | ⛔ **2026-08-01 폐기(§2-3)** |
| 4 | — | — | **현재 유효한 방법 없음. 인젝션 대기.** |

### 2-1. H₂O 교정이 폐기된 이유 (유지)
- H₂O비 r (A 0.820 / B 0.895 / C 0.904)가 **NO₂ 실측 스케일 g (0.904 / 1.043 / 1.012)보다 10~17% 낮음** → 과보정 → NO₂ 비례 **가짜 ANs**.
- 증거: H₂O교정 ANs가 NO₂와 corr **+0.91**. 구간별 ANs = 0.055(0-1ppb) → 0.235(2-4) → **1.200(8+)**.
- **"새벽 5-6h 피크"의 정체 = 그 시각이 NO₂ 최대(3.5 ppb)**.
- ⚠️ H₂O·NO₂는 흡수 파장이 달라 L_eff(λ)가 다름 → r(H₂O) ≠ r(NO₂). 근본 원인.
- CHOCHO 교차검증 → SNR 0.1~0.6으로 실패.

### 2-2. ⛔ 구 채택 방법 (기록 보존 — **더 이상 쓰지 말 것**)
```
에폭별 Theil-Sen:  ch2 = g·ch1 + a
ANs = ch2 − g·ch1        g: A=0.9039  B=1.0426  C=1.0120
```
당시 "검증 4종 통과"라고 했으나, 그 4종은 전부 **회수력(recovery)을 시험하지 않았다** — 즉
"이 방법이 진짜 ANs를 되찾을 수 있는가"를 한 번도 묻지 않았다. 그게 §2-3.

### 2-3. 🆕 **왜 §2-2가 원리적으로 안 되는가 — 합성 주입 회수 테스트**
실데이터(C2, n=24,076)의 ch1을 그대로 쓰고, **알려진 ANs를 주입해 ch2를 합성**한 뒤
(진짜 g=1.000, 스캔노이즈 0.0297ppb) 같은 방법으로 되찾아 보게 했다.

| 주입한 진짜 ANs | 진짜 평균 | 회수값 | **회수율** |
|---|---|---|---|
| 상수 0.10 | 0.100 | 0.100 | 100% ✅ |
| 상수 0.30 | 0.300 | 0.300 | 100% ✅ |
| **0.05 × NO₂** | 0.103 | **−0.000** | **0%** ❌ |
| **0.10 × NO₂** | 0.206 | **0.000** | **0%** ❌ |
| 0.10 + 0.05×NO₂ (혼합) | 0.203 | 0.101 | 50% ❌ |
| 광화학 일주기형 | 0.098 | 0.091 | 94% ✅ |

**NO₂에 비례하는 성분은 100% g에 흡수되어 정확히 0으로 보고된다.**

이유: `ch2 = g·ch1 + a` 회귀는 **cov(ANs, NO₂) = 0을 강제**한다. 그런데 알킬질산염은
NO₂와 같은 VOC+NOx 광화학에서 나오므로 실제로는 양의 상관이다. 따라서 회귀는
**반드시** 진짜 ANs를 g로 빨아들이고 `a`를 음수로 민다.

**지문(관측과 일치):**
- 4개 소epoch 중 3개에서 `a` 음수 = ANs로선 비물리
- corr(일별 a, 일별 NO₂ median) = **−0.447** (진짜 ANs면 **양수**여야 함)
- g를 부분집합별로 재추정하면 크게 움직임 (ep C: NO₂<1에서 0.915 → 전체 1.031 → NO₂>3에서 1.066),
  `a`도 따라 +0.048 → −0.087 → −0.286. **직선모델이면 있을 수 없는 일.**

> **⇒ "a ≈ 0"은 ANs가 없다는 증거가 아니라, 이 추정량이 볼 수 없는 성분이라는 뜻이다.**

### 2-4. 🆕 **진단 정정: 검출한계가 아니라 교정 불확도**
| | 값 | 비고 |
|---|---|---|
| 단일스캔 σ(ch2−ch1) | **0.042 ppb** | 인접스캔 차분, robust |
| 5분 평균(~5스캔) | **0.019 ppb** | |
| 일평균(~1400스캔) | 0.001 ppb | |
| 핏 전파오차 | 0.055 ppb | 실측 산포가 오히려 더 작음(0.7×) |

**랜덤 노이즈는 문제가 아니다.** 실제 한계는 g의 계통불확도:

| g 변동원 | Δg | NO₂=1.9ppb에서 겉보기 ANs |
|---|---|---|
| 시간대별(ep C) | 0.092 | **0.175 ppb** |
| 일별 표준편차(ep C) | 0.042 | 0.080 ppb |
| C1→C2 계단 | 0.053 | 0.101 ppb |
| NO₂<1 vs NO₂>3 | 0.151 | 0.287 ppb |

실데이터 C2에서 **g를 1% 바꾸면 ANs가 0.021 ppb 움직인다.** g=0.94~1.02 범위에서
보고값은 **+0.068 → −0.097 ppb**로 부호까지 뒤집힌다.

> **⇒ 장비 정밀도는 충분하다. 부족한 건 채널 상호교정이다.**
> 이 구분이 중요한 이유: "검출한계 이하"면 할 게 없지만, "교정 불확도 이하"면 인젝션으로 풀린다.

## 4. NO₂ 인젝션 프로토콜 — **임계경로로 격상**
§2-3에 의해, 주변대기 데이터만으로는 g를 구할 방법이 **원리적으로 없다**.
인젝션은 "있으면 좋은 것"이 아니라 **유일한 경로**다.

공통 인렛이면 온도 달라도 무방(ZA·순수 NO₂엔 PNs·ANs 없음 → 두 셀이 같은 값 읽어야 함).
- **여러 농도** 0·2·5·10·20 ppb → 전달함수 `ch2 = g·ch1 + c` 전체 + 직선성
- **여러 시간대** 아침·정오·저녁 → g의 일주기(폭 0.05~0.11)가 진짜 계기 효과인지
- 레벨당 안정 스캔 ~30개(5~10분)
- **필요 정밀도**: ANs를 0.05ppb로 말하려면 **g를 0.3% 이내**로 알아야 한다(NO₂ 2ppb 기준). 설계 시 반드시 반영.
- ⚠️ 사이트→연구실 이전으로 광학 상태가 에폭 C와 다를 수 있음. 그래도 **방법론 검증**은 가능.
- 기존 raw엔 NO₂ 인젝션 flag 없음(1=대기, 500=ZA, 510=He만) → 과거엔 안 함.
