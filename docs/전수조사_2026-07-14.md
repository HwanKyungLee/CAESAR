## 발견했지만 수정하지 않은 것 (잠재/판단 필요)

1. **Temporal I₀ 인덱스 불일치 (레거시, 도달 불가)** — `worker._prescan_za_scans`는
   file_list 인덱스로 ZA를 수집하는데 `_interpolate_i0(za_list, i)`는 확장 스캔
   인덱스로 호출됨. 현재는 raw 직접 핏이 차단(알파 전용)이라 실행 불가 경로.
   → raw 핏 부활 시 반드시 수정. 그전엔 dead code 정리 후보.
2. **doas_fit custom_basis 시 poly_coeffs 오염 (잠재)** — `poly_coeffs =
   c_opt[num_gases:-2]`가 custom_basis 계수까지 포함. 현재 custom_basis=None이라
   무해하나 fixed-pattern 베이스 연결 시 반환 분리 필요.
3. **다채널 저장 공통 헤더** — save()의 # 공통 헤더(poly/λ/robust)와 채널 헤더의
   `refs=`가 활성 채널 값 기준. 채널별 태그 줄이 따로 있어 실害 낮지만 헤더만 보면
   오해 여지.
4. **QC K 기본값 8 vs 캠페인 운용값 6** — 의도된 보수적(과제거 방지) 기본인지 확인
   필요. 시나리오 JSON이 K를 갖고 다니면 무해.
5. **n_air 상수** — worker 2.68678e19 vs physics 2.6867811e19 (0.4 ppm, 무시 가능
   하지만 한 곳으로 통일하면 깔끔).
6. **Settling의 '빈' 정의 의존성** — 정착 스캔 제외는 "α 파일 = raw 1시간 파일 1개"
   구조에 의존(파일 첫 N행 = 주입 직후). α를 일 단위로 병합 생성하도록 바꾸면
   조용히 의미가 깨짐 — α 생성 단위를 바꿀 때 함께 볼 것.
7. **릴리즈 체크리스트와 SKIP** — CHANGELOG 체크리스트는 "6항목 전부 PASS"인데
   외부 데이터 없는 머신에선 4개만 실행됨. 체크리스트에 "SKIP 없는 환경에서" 명시
   필요.
