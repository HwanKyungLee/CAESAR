# CAESAR Pro: BBCEAS 미량기체 리트리벌을 위한 통합 분석 소프트웨어

**— 설계 원칙, 방법론, 그리고 기존 파이프라인 대비 차별점 —**

작성: 2026-07-14 (여수 2026 캠페인 필드미션 종료 시점 기준, v0.1.0 / 코드 약 22,000줄)

---

## 초록

CAESAR Pro는 아라온/여수 CAESAR BBCEAS 시스템의 raw 측정 파일로부터 미량기체
(NO₂, CHOCHO, PNs, ANs 등) 농도를 산출하는 데스크톱 분석 프로그램(Python/PyQt6)이다.
기존 MATLAB 스크립트 파이프라인이 수행하던 α 스펙트럼 생성 → DOAS 피팅 → 시계열 산출
과정을 단일 GUI 안에서 자동화하되, **수치적으로는 기존 파이프라인과의 정합을 단계별로
검증**(raw 파싱 바이트 일치, 타임스탬프 std = 0.0000 s, Rayleigh 단면 문헌값 0.000% 일치)
하면서 다음을 더했다: (1) He/ZA 주입 기반 반사율의 **시간보간 R(t)**, (2) Variable
Projection 기반 비선형 DOAS 피팅의 **멀티코어 병렬화**(순차 결과와 ~10⁻⁶ ppb 수준 일치
검증), (3) 삭제가 아닌 **플래그 기반 비파괴 QC**, (4) 결과 파일에 코드 버전·세팅 전체를
박아 넣는 **재현성(provenance) 체계**, (5) 자동 회귀 검증 도구(파이프라인 6항목, 시각화
24항목). 본 문서는 프로그램의 물리 모델과 알고리즘, 데이터 무결성 철학, 그리고 편의
기능을 기술한다.

## 1. 배경과 설계 목표

BBCEAS 리트리벌은 원리 자체(Fiedler et al. 2003; Washenfelder et al. 2008)보다
**운영상의 세부**가 결과를 좌우한다: 거울 반사율이 시간에 따라 흐르고, ZA/He 주입
사이클의 전환 구간이 보정을 오염시키며, 구름·저광량 스캔이 피팅을 폭주시키고, 수백
GB의 raw 파일을 몇 번이고 재처리해야 한다. CAESAR Pro의 설계 목표는 세 가지다.

1. **물리 우선, 통계 보조** — 보정과 필터링의 근거는 가능한 한 물리(플래그, 주입
   상태, T/P 실측, contrast)에서 나오고, 통계적 임계는 분포 기반(robust MAD)으로
   매직넘버를 최소화한다.
2. **비파괴** — 어떤 자동 처리도 원본 값을 지우지 않는다. 제외는 상태 플래그와 NaN
   마킹으로 하고, 원본은 항상 복원 가능하며, 몇 %가 제외됐는지 숫자로 보고한다.
3. **재현성** — 같은 입력 + 같은 세팅이면 언제 누가 돌려도 같은 출력. 모든 결과
   파일 헤더에 코드 버전(git 해시)과 전체 피팅 세팅이 기록된다.

## 2. 시스템 구성

### 2.1 처리 파이프라인

```
raw .dat (LabVIEW Mega-Matrix, 1시간/파일, 행=스캔)
   │  ① 파싱: 스펙트럼(채널별 2048px) + HK(T/P/플래그) + bytepack 시각
   ▼
R Calibrator ──→ R(t) knots (R_<ch>.npz)      ← He/ZA 주입쌍마다 (1−R)/d
   │
   ▼
Alpha Generator: I₀(t) PCHIP 보간 + R(t) 시간보간 + Rayleigh 차분 보정
   │           → α(λ, t) 60 s 시간평균  (*_alpha_trace.dat, 파장축·T/P·시각 내장)
   ▼
DOAS 피팅 (VarPro + NNLS): 채널별 병렬 → 농도 ppb + 오차 + 품질지표
   │
   ▼
자동 QC(비파괴 플래그) → 일별/세팅별 버킷 저장 → Result Lab / Plot Maker
```

각 단계는 독립적으로 검사 가능하다(중간 산물인 α 파일이 자체 파장축·보정 이력 헤더를
내장). 피팅 입력을 α로 일원화한 것은 의도적 결정으로, raw→α 변환(보정 물리)과 α→농도
(피팅 수학)를 분리해 문제 발생 시 원인 단계를 즉시 좁힐 수 있다.

### 2.2 코드 구조 (관심사 분리)

| 층 | 모듈 | 역할 |
|---|---|---|
| 물리·수학 코어 | `core/physics.py`, `core/doas_fit.py`, `core/engine.py` | Rayleigh, Kalman, VarPro 피터, 레퍼런스 엔진 — GUI 비의존 |
| I/O | `core/raw_parser.py`, `core/data_io.py`, `core/result_io.py` | 컬럼 레이아웃 단일 출처, HK 파싱, 결과 병합/자르기 |
| GUI | `gui/` | 메인 창, 워커 스레드, Result Lab, Plot Maker |
| 도구 | `tools/` | 검증기, R 배치 계산, 진단 스크립트 (CLI) |

핵심 수치 루틴은 **단일 구현 원칙**을 따른다. 예컨대 raw 컬럼 레이아웃 상수는
`raw_parser.py` 한 곳, Rayleigh 물리는 `physics.py` 한 곳, QC 임계식은
`result_io.robust_rms_thresholds` 한 곳에 있고 GUI·CLI·워커가 전부 이를 import 한다.
과거 tools 쪽에 물리 사본이 따로 있어 R이 틀어졌던 사고를 겪은 뒤 확립한 원칙이다.

## 3. 물리 모델

### 3.1 BBCEAS 흡광 계수

ambient 스캔의 흡광 계수는 MATLAB 파이프라인과 동일한 식을 쓴다:

$$\alpha(\lambda) = R_L\left[\frac{1-R(\lambda)}{d} + \alpha_{Ray}^{ZA}(\lambda)\right]\left(\frac{I_{ZA}(\lambda)}{I(\lambda)} - 1\right) - \left[\alpha_{Ray}^{sample}(\lambda) - \alpha_{Ray}^{ZA}(\lambda)\right]$$

- $R_L$ = 퍼지 가스 유효 경로 보정 (CH1 0.9330 / CH2 0.9950 / CH3 0.9968, 실측값).
  $R_L$이 괄호 전체에 곱해지는 위치까지 원본 공식과 대조해 교정했다(과거 구현은
  $R_L$이 소거되는 형태였음을 수치 실험으로 확인 후 수정).
- Rayleigh 차분 항은 ZA 기준 스캔과 ambient 스캔의 T/P 차이를 행별 HK 실측값으로
  반영한다.

### 3.2 Rayleigh 산란: 경험식 → 분산식(Sellmeier)

MATLAB 파이프라인의 σ_ZA 경험식(fminsearch 피팅) 대신 문헌 분산식을 쓴다:
N₂ = Peck & Reeder (1972), O₂ = Bates (1984), He = Cuthbertson & Cuthbertson (1936),
King 보정계수 포함(Bodhaine et al. 1999). σ는 STP Loschmidt 밀도 기준 분자 고유값으로
정의하고 α = σ·N(T,P)로 환산한다. 447 nm에서 σ_ZA가 문헌 골든값과 0.000% 이내로
일치함을 자동 검증기가 상시 확인하며, 경험식 대비 차이는 −3.2% 수준으로 정량화해 두었다.
(구현 과정에서 King factor의 ν² 항이 ν로 잘못 들어가 있던 것, O₂ 상수 1.09→1.096
오타를 발견·교정 — 각각 σ에 ~0.15%, ~0.5% 계통편향을 만들던 항목이다.)

### 3.3 거울 반사율: 단일값이 아닌 R(t)

He/ZA 주입쌍마다 (Washenfelder et al. 2008):

$$\frac{1-R}{d} = R_L\,\frac{r\,\alpha_{Ray}^{ZA} - \alpha_{Ray}^{He}}{1 - r}, \qquad r = I_{ZA}/I_{He}$$

여기서 개별 주입을 **물리 기반 품질 게이트**로 거른다:

- **주입 플래그 엄격 구분** — flag 500(ZA injecting)/510(He injecting)만 채택.
  setflow·wait 전환 구간(501–503/511–513)은 캐비티 미충전이라 배제.
- **He/ZA contrast band** — 정상 사이클의 (I_He−I_ZA)/I_He ≈ 0.17–0.21을 근거로
  0.05–0.35 밖은 사이클 통째 제외(ZA dropout, ZA≥He 역전 검출).
- **비물리 R 검출** — clip 전(unclipped) R로 판정. R을 1.0으로 clip한 뒤 판정하면
  비물리 사이클이 R=1.000으로 "위장"되어 품질체크를 통과하는 버그를 겪고 확립한 규칙.

통과한 주입쌍들은 시간 knot가 되어 **PCHIP으로 시간보간된 R(t)**를 만든다(경계 밖은
최근접 상수). 종전 방식(런 전체 단일 R)은 런 경계마다 Leff가 점프하고 R의 일변화
정보를 잃었다. 같은 논리로 **I₀(t)도 ZA 블록평균들의 PCHIP 보간**이다 — 단일 스캔
노이즈(~1%)가 α에 그대로 들어가지 않도록 주입 블록 단위로 평균한 뒤 보간한다.

### 3.4 시각과 환경 변수

- 행별 시각은 LabVIEW bytepack `(col0<<16)|col1` = 연초 기준 센티초를 직접 읽는다.
  기준 .mat의 doy와 표준편차 0.0000 s로 일치함을 검증했다. 행 간격을 0.97 s 상수로
  합성하지 않으므로 주입/공백 구간을 넘어 평균되는 오류가 없다.
- T/P는 행별 HK 컬럼 실측값. 파일 꼬리가 잘린 비정상 행(LabVIEW 기록 중단)도 HK
  시프트 추론 + 압력 타당성 게이트(800–1200 mbar)로 복구한다. 복구 실패 시 기본값
  폴백 행 수를 경고로 보고한다(조용한 폴백 금지).
- 열분해 채널(180/300 °C)의 ppb 밀도보정은 셀히터 설정값(75 °C)이 아니라 실측
  tempcell(CH1≈34 °C)을 쓴다 — n_air 계통오차를 없앤 항목.

## 4. DOAS 피팅 알고리즘

### 4.1 모델과 Variable Projection

핏 모델은

$$\alpha(\lambda) = \sum_i c_i\,\sigma_i\big(\lambda;\,s_i,\,q_i\big) + \sum_{j=0}^{P} p_j\,T_j(x) + a\sin(f\lambda) + b\cos(f\lambda)$$

- 기체 단면 σᵢ는 픽셀공간 shift $s_i$·squeeze $q_i$(비선형)와 계수 $c_i$(선형)를 가진다.
- 베이스라인은 Chebyshev 다항식(수치 안정성을 위해 핏 윈도우를 [−1,1]로 사상).
- Etalon fringe는 주파수를 FFT로 1회 검출한 뒤 **sin·cos 두 선형 열**로 흡수한다
  — A·sin(fx+φ) = A cosφ·sin(fx) + A sinφ·cos(fx) 항등식으로 위상을 비선형
  파라미터에서 제거해, 같은 모델 공간을 유지하면서 전역 선형해를 보장한다.

비선형 파라미터(shift/squeeze)는 `scipy.least_squares`로, 내부 선형 문제는 Variable
Projection으로 매 반복 해석적으로 푼다. 선형해에는 선택적으로:

- **NNLS / ±Neg** — 기본은 기체 계수 하한 −∞(음수 허용). 0 하한(NNLS)은 0 근처
  농도의 양의 정류(rectification) 편향을 만들기 때문에, PNs = CH1−CH2 같은 차분량이
  비편향이 되도록 음수를 허용하는 것을 기본으로 한다(통계적으로 올바른 선택이며,
  개별 음수값은 노이즈로서 평균에서 상쇄된다).
- **Tikhonov 능형화** — λ>0 시 기체·etalon 열만 수축하고 다항식 배경 열은 수축하지
  않는다(배경 왜곡→기체 과소편향 방지).
- **Robust IRLS (Tukey biweight)** — 스파이크/우주선 자동 강건화(옵션).

### 4.2 Shift/Squeeze 제어 — 기체별 4모드

기체마다 shift와 squeeze를 독립적으로 **Limit(구간 제한) / Fix(절대값 고정) /
Free / Link(다른 기체에 연동)** 로 지정할 수 있다. 여기에 **스캔 간 step limit**
(프레임당 최대 이동 px)을 결합해, 시간축에서 shift가 서서히 흐르는 것은 따라가되
단일 스캔이 폭주하는 것은 막는다. 콜드 채널처럼 개별 스캔의 SNR로는 shift를 정할 수
없는 경우 Fix 0 + 시간축 캐리오버 전략을 쓴다(이는 캠페인 데이터로 확인한 운영 규칙).

### 4.3 품질 지표와 오차

행마다 RMS, reduced χ²(픽셀 노이즈는 von Neumann 추정 σ = std(diff)/√2 — 스펙트럼
구조에 오염되지 않는 노이즈 추정), DOF, SNR을 산출한다. 농도 오차는 선형해 공분산에서
전파하고, n_air의 T/P 불확도(±1 °C, ±1 mbar)를 합성한 total error와 MDL(3σ)을
함께 기록한다. 스무딩(Kalman)은 **별도 _Smooth 컬럼**으로만 출력한다 — 주 컬럼은
항상 raw 핏 결과다(화장은 raw와 같이 제출한다는 원칙).

### 4.4 병렬화 — 순차와의 동일성을 검증한 청크+워밍업

스캔 간 캐리오버 상태가 last_valid_shift 하나뿐(α 입력에는 I₀/R 캐리오버 없음)이라는
점을 이용해, 연속 스캔을 청크로 나누고 각 청크 앞에 40스캔 워밍업을 붙여 shift를
재정착시킨 뒤 본체를 피팅하는 방식으로 멀티프로세스 병렬화했다. **실제 콜드 α 데이터로
순차 결과와 per-scan 대조해 ~10⁻⁶ ppb 수준 일치를 확인**한 뒤 기본 모드로 채택했다.
BLAS 스레드를 워커당 1로 캡해 과구독을 방지하고, 총 프로세스 예산(논리코어의 절반)을
채널 수로 나눠 다채널 동시 피팅에서도 부하가 일정하다. α 생성 쪽도 파싱(CPU 병목)만
프로세스풀로 돌리고 분류·계산은 메인에 남겨 **순차 경로와 바이트 동일**함을 검증했다.

## 5. 데이터 무결성과 QC

이 프로그램의 QC는 "지우지 말고 플래그하라"는 원칙 위에 있다. ppb·ppt 스케일 연구에서
과필터링은 과소필터링보다 위험하다(제거된 데이터는 돌아오지 않는다).

1. **비파괴 플래그** — QC 제외는 가스값 NaN + Status 문자열(`QC-Auto (rms=…)`,
   `Settling` 등)로 표시된다. 원본 농도는 내부에 백업되어 QC 파라미터를 바꿔
   **재핏 없이** 몇 번이고 재적용(Reapply)할 수 있다.
2. **분포 기반 임계** — RMS 이상치는 채널별 log₁₀ 공간에서
   thr = 10^(median + K·MAD) 로 잡는다. 매직넘버 대신 감도 K 하나만 노출되며,
   같은 식 하나(`core.result_io`)를 핏 직후 QC·Result Lab 표시·내보내기가 공유한다.
3. **물리 사유 우선** — 절대 RMS 상한(구름/저광량은 상대 RMS를 통과하고 절대 RMS로만
   잡힘), SNR 하한, 정착(settling) 스캔(He/ZA 복귀 직후 캐비티 미충전으로 농도가
   저편향되는 각 사이클 첫 ~3빈, 실측 −16% 편향 확인 후 도입) 등 제외 사유가 모두
   기록된다.
4. **입력 오염 방어** — α 생성 입력은 측정 파일명 규칙(`YYYY-MM-DD-NNN`)
   화이트리스트로 거른다. raw 폴더에 섞인 분석 산출물(.dat)이 스캔으로 오인 파싱되어
   전 기간 α를 오염시킨 실제 사고(2026-07-09) 후 도입된 방어다.
5. **재현성** — 모든 결과 파일 상단에 코드 버전(git 해시), 핏 윈도우, 다항식 차수,
   λ, Robust, ±Neg, QC 세팅, 보정 이력(R 출처, I₀ 모드, dark/offset/stray)이 #
   헤더로 기록된다. 저장은 날짜/±Neg/QC 버킷 폴더로 자동 라우팅되고, 같은 세팅
   재핏 시 기존 파일은 삭제가 아니라 mtime을 붙여 `_archive/`로 이동한다.

## 6. 자동 검증 (회귀 가드레일)

수정이 잦은 연구 코드에서 "고치다 딴 데가 깨지는" 문제를 막기 위해 두 검증기를
상시 운용한다:

- **`tools/validate_pipeline.py`** — raw 파싱(Python==MATLAB 바이트 대조), 파장보정
  (Hg 라인 ±0.07 nm), 레퍼런스 ILS, Rayleigh 물리(문헌 골든값), R·Leff 물리성,
  핏 출력 타당성의 6항목 자동 PASS/FAIL. 코드 수정 후와 릴리즈 태깅 전 필수 실행.
- **`tools/validate_plotmaker.py`** — 시각화 24항목. 미리보기(pyqtgraph)와 출판
  (matplotlib) 이중 렌더 경로의 동작 일치(눈금·라벨·리샘플 등)를 뮤테이션 테스트로
  검출력까지 확인한 스위트.

이 외에 단계별 1회성 검증(MATLAB α 대조, 타임스탬프 대조, 병렬=순차 대조 등)의
스크립트·결과는 `diagnostics/`에 FINDINGS 문서와 함께 보존된다.

## 7. 워크플로와 편의 기능

### 7.1 채널 탭과 시나리오

왼쪽 패널 상단의 채널 탭은 채널마다 독립 세팅(레퍼런스 세트, 파장보정, 핏 윈도우,
다항식 차수, 시간 시프트, 가스온도)을 보유하고 RUN 시 **채널별 워커가 병렬**로 돈다.
전 채널 세팅은 시나리오 JSON으로 저장/복원되어(예: Cold 775–1550px/4차/NO₂·CHOCHO·H₂O)
"박사님 세팅 그대로"를 클릭 한 번에 재현한다.

### 7.2 사고 예방 장치

- **RUN 확인 다이얼로그** — 실행 직전 채널별 wavecal 파일명·윈도우·레퍼런스·시프트·
  가스온도를 한 화면에 요약해 확인받는다(구버전 wavecal로 밤샘 핏을 돌리는 사고 방지).
- **Test Fit(1스캔)** — 첫 α 스캔만 즉석 피팅해 데이터+모델 오버레이, 잔차, 농도,
  shift를 팝업으로 확인 — 장시간 RUN 전 세팅 검증.
- **wavecal 상시 표시** — 현재 채널에 로드된 파장보정 파일명이 패널에 항상 보인다
  (안 보여서 생긴 오정렬 사고 재발 방지).
- **레퍼런스 Lock** — 레퍼런스 변경은 명시적 Lock(commit)으로만 엔진에 반영되고,
  Lock 없이 RUN하면 경고한다.
- **크래시 대비 자동저장** — 결과 도착마다 TSV append(밤샘 런 크래시 복구),
  완료 시 정식 자동저장은 별도.

### 7.3 Result Lab과 Plot Maker

- **Result Lab** — 저장된 결과(R 트렌드, R 커브, α, 레퍼런스, 농도 시계열)를 형식
  자동 인식으로 열람. 기간 선택 자르기/병합(중복 행은 나중 파일 우선 규칙), QC
  사후 재적용, 다단계 수식 계산기((A−B)/C, 시간정렬, AST 안전평가), 핏 행 클릭 →
  해당 α 스펙트럼 팝업 추적.
- **날짜 로더** — 기간을 고르면 일별 파일을 자동 병합(파생물은 `_derived/` 캐시,
  mtime 무효화)하는 공용 다이얼로그를 Result Lab·Plot Maker가 공유.
- **Plot Maker** — 여러 결과를 메모리에 올려 시계열/산점도/일변화(diurnal)/Allan
  합성. 드래그 순서, Undo, 시리즈별 스타일, 미리보기(pg)=출판(mpl) 패리티 검증,
  Batch Publish(종별 그림 일괄 출력), 박사님 그림 규약(공백=마커, x범위 tight,
  종별 색 통일) 프리셋.
- **R Calibrator** — 좌패널 채널 세팅을 자동 상속해 채널별 R 시계열을 계산·저장.
  npz 증분(이미 계산된 날은 재스캔 0), 빈 날 검증(Verify), α용 R(t).npz 내보내기.

### 7.4 성능

| 항목 | 개선 |
|---|---|
| 100 MB×1200파일 인덱싱 | 행수 디스크 캐시 + 바이너리 카운트: 첫 1회 후 0 s (구현 전 ~7시간) |

## 8. 기존 MATLAB 파이프라인 대비 차별점 요약

| 측면 | MATLAB 파이프라인 | CAESAR Pro |
|---|---|---|
| R | 런/일 단위 단일값에 가깝게 운용 | 주입쌍별 knot → PCHIP **R(t)** 시간보간, 물리 게이트로 불량 주입 자동 배제 |
| I₀ | 블록 평균 | ZA 블록평균의 **PCHIP I₀(t)** (램프 드리프트 추적) |
| Rayleigh | 경험식(피팅 계수) | Sellmeier 분산식 + King 보정, 문헌 골든값 자동 검증 |
| Etalon | — | 주파수 FFT 검출 + sin/cos 선형화(전역해) |
| Shift/Squeeze | 스크립트별 고정 | 기체별 Limit/Fix/Free/Link + step limit + 시간축 캐리오버 |
| QC | 수동/육안 | 분포 기반 자동 + 물리 사유별 비파괴 플래그, 재핏 없는 재적용 |
| 처리 속도 | 단일 스레드 | 파싱·피팅 멀티프로세스(순차 동일성 검증됨) |
| 재현성 | 스크립트 버전 관리에 의존 | 결과 파일에 git 해시+전체 세팅 자동 스탬프, `_archive` 비파괴 버전 보존 |
| 검증 | 1회성 | 상시 회귀 검증기 2종(파이프라인 6항목·시각화 24항목) |
| 접근성 | 스크립트 편집 필요 | GUI + 시나리오 JSON, 사고 예방 확인 장치 |

**정합성**: 위 차별점들은 기존 파이프라인을 대체하기 전에 단계별 대조를 거쳤다 —
raw 파싱 바이트 일치, bytepack 시각 std 0.0000 s 일치, α 생성 MATLAB 대조
(`diagnostics/alpha_vs_matlab_2025_06_11`), Rayleigh Python vs MATLAB 경험식 차이
−3.2% 정량화(물리식이 문헌값과 일치), 병렬 핏 = 순차 핏 ~10⁻⁶ ppb.

## 9. 한계와 향후 개선 (Discussion)

솔직한 한계를 명시한다.

1. **콜드 채널 잔차의 고정 패턴** — 콜드 잔차의 fixed/random 성분비가 커서 NO₂
   불확도가 잔차 구조에 의해 제한된다. H₂O/O₄ 레퍼런스 보강과 고정패턴 고유벡터를
   핏 베이스에 넣는 실험(`custom_basis` 인프라는 구현되어 있으나 미연결)이 다음
   단계다.
2. **오차 예산의 체계화** — 현재 오차는 핏 공분산 + n_air 전파까지다. σ(R), σ(d),
   단면 문헌 불확도까지 합친 계통오차 예산 보고는 미구현이다.
3. **Hot 채널 스케일** — CH1/CH2 스케일 슬로프가 광학 얼라인먼트 상태와 강상관
   (r≈+0.76)임을 확인했으나, ANs 실제/열적 성분 분리와 기간별 보정 적용 여부는
   미결이다.
4. **레거시 경로** — raw 직접 피팅 경로(AnalysisWorker 내)는 보존되어 있으나 현재
   워크플로에서는 차단되어 있고, 그 안의 Temporal I₀ 보간은 인덱스 기준이 구식이다
   (도달 불가 경로지만 정리 대상).
5. **패키징** — v0.1.0에서 경로 이식성은 확보했으나 커밋/태깅과 의존성 고정 배포는
   진행 중이다.
