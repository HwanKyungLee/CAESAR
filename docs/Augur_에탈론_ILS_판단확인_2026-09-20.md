# 에탈론·ILS 판단 확인 (7차, 2026-09-20)

합성시험 원자료(`varpro_synth_results.csv`)를 직접 열어 검증했다.

## 1. 에탈론 이중계상 — 맞다. 4.90 % 행을 삭제한다

`g3b_unmodeled_etalon` 원자료:

| f_true | Δf | A=1 % | A=3 % | A=10 % |
|---|---|---|---|---|
| **0.12 (핏 가정과 일치)** | 0 | +2.2e-13 % | +1.7e-13 % | **+6.1e-14 %** |
| 0.08 | 0.04 | **−4.876 %** | −14.39 % | −43.39 % |
| 0.20 | +0.08 | +0.663 % | +2.00 % | +6.83 % |
| 0.35 | +0.23 | −0.048 % | −0.142 % | −0.443 % |

**주파수가 맞으면 진폭 10 %에서도 편향이 6e-14 %다.** 시험의 설계가 그렇다 —
"진폭 항"이라는 독립 항은 존재하지 않고, 4.90 %는 **Δf = 0.04 일 때의 주파수
오지정 효과**다. T2 가 실측 Δf 로 같은 항을 이미 쟀으므로 **두 줄을 함께 올리면
이중계상**이다. 삭제에 동의한다. 합성 표는 부록에 감도 시연으로 남긴다.

### 다만 역산 진폭(0.1~0.25 %)은 ANs·cold 에만 쓸 것

위 표에서 보이듯 **응답이 Δf 에 단조가 아니다** — Δf 0.04 에서 −4.88 %로 최대,
0.08 에서 +0.66 %, 0.23 에서 −0.05 %. 가까운 주파수가 핏 기저와 맥놀이를 일으켜
기체 열로 새고, 멀면 오히려 다항식·잔차가 먹는다.

실측 Δf 는 PNs **+0.017** · ANs +0.039 · cold +0.044 다. ANs·cold 는 합성 격자의
0.04 에 가까워 역산이 성립하지만, **PNs 의 +0.017 은 격자 밖**이고 그 구간의 응답은
모른다(0 과 0.04 사이에서 급격히 커지는 구간일 수 있다). **PNs 에 대해 역산 진폭을
인용하지 말 것.**

## 2. ★ 주파수 항은 **하한**이다 — Fig 4 전에 한 번 더 재야 한다

T2 가 잰 것은 **두 고정값의 차**(f=0.12 vs 채널 최빈값)이지 **고정값과 진실의 차**가
아니다. 그리고 T2 자신이 최빈 bin 점유율을 PNs·cold 에서 **18~32 %** 로 보고했다 —
즉 진짜 f 가 스캔마다 흩어져 있어서 **어떤 고정값을 쓰든 대부분의 스캔에 잔여
불일치가 남는다.**

> 올바른 측정: **운영 고정 f 핏 vs 스캔별 검출 f 핏**의 차 분포.
> `core.param_optimizer.fit_scan` 이 이미 스캔마다 f 를 재검출하므로 기계는 있다
> (T1 1차에서 그게 오염원이었던 바로 그 기능이다).

이 측정 전에는 **에탈론 주파수 행을 "하한"으로 표시**해야 한다. 값이 2.2×1σ 로
세 번째로 큰 항이라, 하한인 채로 Fig 4 를 확정하면 나중에 다시 그려야 한다.
**한 번 돌리고 Fig 4 로 가는 것을 권한다.**

## 3. ILS — VERIFIED 에 동의. 다만 근거를 하나 보태야 한다

`g3a_ils_mismatch` 원자료 (추가 FWHM → NO₂ 편향):

| 추가 FWHM | px | NO₂ 편향 |
|---|---|---|
| 0.0120 nm | 0.25 | **+7.3e-14 %** (변화 없음) |
| 0.0240 nm | 0.5 | −1.3e-5 % |
| 0.0481 nm | 1.0 | −0.048 % |
| 0.1442 nm | 3.0 | −0.693 % |

실측 불일치 **0.02 nm ≈ 0.5 px** 에서 편향은 **~1e-5 %** 로, 제시한 "<0.05 %"보다도
훨씬 작다. VERIFIED 로 올리는 데 동의한다.

**단, 이 무해함의 일부는 구현 특성 때문이다.** 0.25 px 추가에서 편향이 **정확히
변하지 않는다** — 합성곱 커널이 정수 픽셀 격자에서 `radius = int(4σ)+1` 로 샘플링되어
**약 0.25 px 이하의 ILS 변화는 커널을 전혀 바꾸지 못한다**(이 저장소의 기존 발견).
따라서 논문 서술은 이렇게 되어야 한다:

> 실측 ILS 불일치는 0.02 nm 이고 그 수준에서 검색 감도는 1e-4 % 미만이다. 다만
> 합성곱 커널이 정수 픽셀에서 샘플링되므로 약 0.25 px 이하의 ILS 차이는 커널을
> 바꾸지 않는다는 점을 함께 적는다(§2.7).

"감도가 없다"와 "표현할 수 없다"를 구분해 적어야 심사에서 걸리지 않는다.

**빠진 수치 하나**: 핫 채널의 불일치가 nm 로 제시되지 않았다(cold 만 0.765 vs 0.785).
roi1/roi2 레퍼런스 반치폭 9.40 px 에 대응하는 nm 와 Hg 실측 0.684/0.688 nm 의 차를
명시해 달라 — 표에 "<0.05 %"를 세 채널 모두에 적으려면 필요하다.
