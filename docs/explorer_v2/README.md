## 목적과 문서 우선순위

해당 미션의 alpha, 파장축, 임의의 reference 집합으로 실제 피팅을 반복하여
미션에 적합한 FitSet과 동등 대안을 추천한다. 수동 FitSet과 외부 농도 정답은 필수가 아니다.
수동 FitSet은 선택적 비교 후보다. 기본 관심종은 등록된 모든 종이며 사용자가 우선순위를
선택할 수 있다. 정합을 주도하는 reference와 농도를 보고할 관심종은 서로 다른 개념이다.

V2 신규 구현은 이 패키지의 계약을 따른다. 기존 문서는 V1 동작과 역사적 evidence의 설명으로
보존한다. 이 문서가 만들어졌다고 현재 코드나 기존 결과의 판정이 바뀐 것은 아니다.

## 고정 원칙

- 기체명, 채널명, 특정 미션 경로를 알고리즘 조건으로 사용하지 않는다.
- 레퍼런스는 흡수 모델의 구성 요소다. 외부 검증이나 종별 이론량 검사는 별도 증거다.
- 외부 검증 부재는 내부 추천을 차단하지 않는다. 적용 가능한 물리 위반은 무시하지 않는다.
- 같은 관측행에서 설정을 바꾼 차이를 비교한다. 날짜 사이 농도가 일정할 것을 요구하지 않는다.
- 수치 seed 재현성과 모델 설정 민감도에 서로 다른 기준을 쓴다.
- bounds만 달리한 같은 해는 bounds 재현성 증거다. 창·poly·reference 강건성을 대신하지 않는다.
- reference 제외는 진단 실험이다. 낮은 잔차나 안정성만으로 필요한 종을 자동 삭제하지 않는다.
- 비검출·낮은 신호와 solver 다중 해를 구분한다. 한 종의 신호 부족으로 모든 종을 탈락시키지 않는다.
- alpha 재생성은 전처리 실험이다. 입력 raw 부분집합이 달라지면 I0 보간 등도 달라질 수 있으므로
  단순 헤더 갱신 또는 기존 운영 alpha의 동등 재현이라고 부르지 않는다.
- holdout은 후보·기준 동결 후 한 번 평가한다. 확인 후 조정했다면 탐색 데이터로 재분류한다.
- 자동 Apply 없음. 사용자의 내보내기 동작으로 새로운 FitSet 파일을 저장한다.

## 추천 방법

입력 검사 → 유한 후보 계획 고정 → 동일 표본 다회 피팅 → 같은 행의 설정 민감도 비교
→ 선언된 이웃 검사 → 후보 동결 → 독립 holdout → 추천 카드·FitSet 내보내기.

창, poly, reference 구성, 정합 정책 축을 평가한다. 연속·정수 축은 명시한 격자 이웃,
범주형 축은 명시한 비교 edge를 쓴다. 범주를 임의 순서로 나열해 거리를 만들지 않는다.
closure는 유한 도메인·예산 안에서 수행한다. 미평가 frontier는 실패 경계로 바꾸지 않는다.
성분 내 인접 pair 통과만으로 먼 양끝의 일치를 가정하지 않는다. 대표와 성분 전체의 차이도 검사한다.
설정 간 shift 수치는 좌표/정합 규약이 같을 때만 비교한다.

추천 후보는 요구된 검사를 통과한 영역에서 선택한다. 잔차 구조와 민감도를 함께 검토하고,
동등하면 자유도·poly 등 복잡도가 낮은 후보를 우선한다. graph hop 수와 넓은 창은 단독 품질 기준이 아니다.
여러 종의 요구가 상충하면 대안을 보여주고 임의 가중합으로 숨기지 않는다.

## 완료 기준

GUI에서 수동 FitSet 없이 미션 입력 → 후보 계획 → 실행/재개 → 종별 추천/잠정/보류
→ 새 FitSet 내보내기가 가능해야 한다. 다른 채널명·종명을 사용해도 코드 수정 없이 작동해야 한다.
외부 검증 없는 사례의 추천, 저신호 종의 제한적 보고, 다중 해 사례의 보류를 각각 검증한다.
일부 실데이터의 추천 성공은 모든 미션의 농도 정확도를 증명하지 않는다.

## 모델별 역할

아스트라: 과학적 주장, 허용오차 근거, 평가 분할, schema 변경 및 주요 체크포인트 검토.
테라: 확정 계약 안의 loader, adapter, evaluator, graph, CLI/GUI, export 구현과 관련 검사.
테라는 기준을 발명하거나 기존 FAIL/UNAVAILABLE을 PASS로 바꾸지 않는다. 충돌이 있으면
관련 파일·재현 사례·필요한 결정을 progress에 적고 독립적으로 가능한 작업을 수행한다.
모든 작은 커밋에 상위 모델 검토를 요구하지 않는다. 카드 2·4·6에서 묶어서 검토한다.
