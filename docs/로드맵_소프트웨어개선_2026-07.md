## A. 과학 기능 — 문헌 벤치마크에서 나온 것

### A-1. Allan deviation 기반 MDL·최적 평균시간 자동 리포트  [효과 상 / 난이도 하]

**현황**: Plot Maker에 Allan 플롯은 있음. 하지만 "이 캠페인의 MDL은 X pptv
@ 평균 Y초"를 자동 산출·문서화하는 정식 루틴은 없다.

**문헌 근거**: IBBCEAS 커뮤니티는 Allan 분석으로 최적 평균시간과 MDL을
보고하는 게 표준 관행이다 — 예: NO₂ 5 pptv @ 1748 s, 29 pptv(2σ) @ 30 s,
10 ppt @ 1000 s 등 기기마다 Allan 곡선으로 제시(IBBCEAS 리뷰, MDPI Sensors
2018). 우리도 논문 Table에 이 숫자가 반드시 필요하다.

**구현**: ZA(제로가스) 장기 구간 or 야간 저변동 구간을 자동 선별 → Allan
deviation 곡선 + 백색잡음 기울기(τ^-1/2) 이탈점 = 최적 평균시간 → 채널·종별
MDL 표를 결과 폴더에 자동 저장. 기존 Allan 코드 재사용이라 난이도 낮음.

### A-2. 계통 불확도 예산 자동화  [효과 상 / 난이도 중]

**현황**: 핏 공분산 + n_air(T/P)만. σ(R), R_L, 단면 문헌 불확도, 파장보정
잔차는 미합산.

**문헌 근거**: BBCEAS 논문들은 전체 불확도를 항목별 RSS로 보고한다 — 예:
NO₂ 총 6.7~6.9%, 단면 ~2%, (1−R)/d ~1.3–2% 등(IBBCEAS 리뷰·개별 기기 논문).
우리 강점(R(t) knot 산포를 이미 가짐)을 살리면 σ(R)을 실측 기반으로 넣을
수 있다 — 문헌보다 나은 부분.

**구현**: 종별 예산표(단면·R·R_L·d·T/P·핏)를 결과 헤더+별도 리포트로.
R 불확도는 R(t) knot 잔차에서, 단면은 문헌값 상수 입력.

### A-3. 파장 의존 ILS (slit function(λ))  [효과 중 / 난이도 중]

**현황**: 채널당 FWHM 하나(+로렌츠 성분)로 전 파장 컨볼브.

**문헌 근거**: QDOAS는 비대칭·파장 의존 슬릿함수 생성을 지원한다 — 넓은 핏
윈도우에서 ILS가 파장에 따라 변하면 잔차에 구조가 남는 것이 알려진 문제.
**우리 콜드 고정패턴의 후보 원인이기도 하다** — 고정패턴 잡기 전에 이것부터
배제하는 순서가 맞다.

**구현**: Hg 라인이 핏 윈도우 안팎 여러 개 있으니 라인별 FWHM을 실측해
FWHM(λ) 보간 → 컨볼루션을 구간별로. 검증은 잔차 고정패턴 크기 변화로.

### A-4. H₂O 간섭 반복(iterative) 제거  [효과 중 / 난이도 중]

**현황**: H₂O를 선형 기저로 같이 핏.

**문헌 근거**: 도시권 glyoxal/NO₂ BBCEAS 논문(Liang et al. 계열)은 H₂O
간섭을 반복 계산으로 제거한다 — H₂O는 흡수가 세고 라인이 포화 근처라
단면×농도의 **선형 근사가 깨지는**(비선형 흡수) 영역이 생기기 때문.
콜드 채널 잔차의 또 다른 후보.

**구현**: 1차 핏 → H₂O 농도로 고분해능 투과율 계산 → ILS 컨볼브해 α에서
제거 → 재핏 반복(2~3회 수렴). validate_pipeline에 회귀 항목 추가 필수.

### A-5. 온도 의존 단면 세트  [효과 중 / 난이도 하~중]

**현황**: 단면 1개 + 1차 온도계수 보정(σ_eff = σ_ref(1 + t_coeff·ΔT/100)).

**아이디어**: NO₂ 단면은 온도의존이 잘 알려져 있고(220–294 K 문헌 세트),
열분해 채널(180/300 °C)은 외삽 영역이라 1차 보정의 한계가 있다. 두 온도
단면을 **동시에 핏**하고 계수비에서 유효온도를 역산하는 방식(위성 DOAS
표준 기법)이 더 견고하다.

### A-6. Intensity fitting 모드 (OD 핏의 대안)  [효과 하 / 난이도 중]

**문헌 근거**: QDOAS는 DOAS(광학두께) 핏과 intensity 핏을 둘 다 제공한다.
강도 공간 핏은 log/비율 변환 전 노이즈 구조를 보존해 저 SNR에서 유리할 수
있다. 우리는 α(선형) 핏이라 이미 비슷한 이점을 갖지만, raw 직접 핏을
부활시킨다면 이 프레임으로 가는 게 맞다. (당장은 우선순위 낮음 — 아이디어
보관.)

※ 참고: QDOAS의 Ring effect(회전 라만) 보정은 **산란 태양광** 전용이라
LED 능동광원인 우리에겐 불필요 — 도입 안 하는 것이 맞다는 근거로 기록.

### A-7. 에어로졸/광대역 소광 진단 컬럼  [효과 중 / 난이도 하]

**아이디어**: 인렛 필터를 통과한 미세 에어로졸이나 필터 열화가 생기면
광대역 소광이 늘어 폴리 배경이 그걸 먹는다 — 지금은 그 정보가 버려진다.
핏의 폴리 0차항(또는 α 광대역 성분)을 시계열 컬럼으로 내보내면 **필터 교체
시기·인렛 손실 진단**이 공짜로 생긴다. BBCEAS로 PM 소광까지 재는 논문이
있을 만큼(BBCEAS+PM 동시측정 논문) 이 신호는 물리적으로 의미가 있다.

## B. 신뢰성·QA — 검증 체계의 다음 단계

### B-1. 합성 스펙트럼 end-to-end 셀프테스트  [효과 상 / 난이도 중]

**아이디어**: 알려진 농도로 α를 **합성**(단면×농도 + 폴리 + etalon + 노이즈)
→ 전체 파이프라인에 통과 → 입력 농도 복원 확인. 지금 검증기는 "결과가
안 변했나"(회귀)를 보는데, 이건 "결과가 **맞나**"(정확도)를 본다.
바이어스·MDL·간섭 매트릭스(종 간 crosstalk)를 정량화할 수 있는 유일한 방법.

### B-2. CI 연동 (GitHub Actions)  [효과 중 / 난이도 하]

validate_pipeline + validate_plotmaker(+B-1)를 push마다 자동 실행.
지금은 사람이 기억해서 돌린다 — 릴리즈 체크리스트의 자동화.
외부 데이터 필요한 2항목은 소형 픽스처 파일을 repo에 동봉해 SKIP 해소.

### B-3. 스팬 체크 워크플로  [효과 중 / 난이도 하]

NO₂ 표준가스 주입 구간을 플래그로 인식 → 기대농도 대비 회귀 → 스케일
정합 리포트. 디스커션 아젠다 C-2(상호비교)의 소프트웨어 쪽 준비물.

### B-4. 이상 감지 대시보드 (캠페인 건강 모니터)  [효과 중 / 난이도 중]

이미 갖고 있는 진단량들 — R(t) knot 기각률, contrast 중앙값, ZA 흡수 구조
(실린더 오염), 신호세기(얼라인먼트), HK 폴백률, 잘린 파일 수 — 을 하루 한 장
"기기 건강 리포트"로 자동 출력. 2026 캠페인에서 겪은 사고들(실린더 만료,
ZA dropout, 파일 트렁케이션, 얼라인먼트 드리프트)이 전부 이 지표들로 **사전
감지 가능**했다는 게 근거. 선상 무인 운용에 특히 유효.

### B-5. 결과 파일 표준 포맷 내보내기  [효과 중 / 난이도 하]

캠페인 데이터 제출·타 그룹 공유용 ICARTT(.ict) / NetCDF(CF-1.x) 내보내기.
지금 TSV+헤더는 사람에겐 좋지만 아카이브 표준이 아니다. 논문 데이터
가용성(availability) 요구에도 대응.

## 추천 실행 순서 (효과 × 난이도 × 의존관계)

```
지금 바로:   D-1 태깅 → B-2 CI (검증 자동화 기반 확보)
캠페인 후속: A-1 Allan/MDL → A-2 불확도 예산   (논문 Table 재료)
과학 개선:   A-3 ILS(λ) → A-4 H2O 반복제거 → 고정패턴 기저(기존 백로그)
             ※ 이 순서인 이유: 고정패턴의 '설명 가능한 원인'부터 소거
검증 강화:   B-1 합성 셀프테스트 → D-5 QDOAS 교차검증
운영 개선:   B-4 건강 대시보드 → C-1 핫 원클릭 → C-2/C-3 속도
```

**한 줄 철학**: 다음 단계의 중심은 기능 추가가 아니라 **"불확도를 말할 수
있는 소프트웨어"**로 가는 것 — MDL(A-1)·예산(A-2)·정확도 셀프테스트(B-1)·
외부 교차검증(D-5)이 그 네 기둥이다.
