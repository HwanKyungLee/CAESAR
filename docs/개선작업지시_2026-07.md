## 작업 A. R(t)/I₀(t) 계단 변화 가드 (step-change guard)

**문제**: R(t)와 I₀(t)는 knot들을 PCHIP으로 보간한다. 거울 청소·재정렬·급오염
같은 **계단형 변화**가 knot 사이에서 일어나면 PCHIP이 이를 램프(경사)로 뭉개서
그 구간의 α가 계통적으로 틀어진다. 현재 방어는 knot 이상치 밴드([0.5×, 2×] Leff)와
contrast 게이트뿐 — "게이트를 통과하는 진짜 계단"을 감지해 보간을 끊는 로직이 없다.

**위치** (grep 힌트):
- R(t) 사전계산: `tools/rt_precompute.py` (R_<ch>.npz 생성, knot 배열 저장)
- R(t) 소비: `gui/worker.py`의 AlphaExportWorker(rt_path=) — PCHIP 보간부
  (`PchipInterpolator` grep)
- I₀(t): 같은 worker의 ZA 블록평균 → PCHIP 경로
- R Calibrator GUI: `gui/ui_dialogs_r.py`, `gui/r_workers.py`

**설계 제안**:
1. 인접 knot 간 상대 변화율 검사 — 예: |ΔLeff|/Leff 또는 |Δ(1−R)/d| 가
   문턱(기본 제안: 창 중앙 파장 기준 수 %/knot 간격, 실데이터 분포 보고 결정)을
   넘으면 그 사이를 "계단 후보"로 표시.
2. 계단 후보 구간은 PCHIP을 **관통시키지 않고 분절**: 좌측 구간은 좌측 knot들만,
   우측 구간은 우측 knot들만으로 보간(경계는 최근접 상수). npz에 분절 경계 저장.
3. **수동 분절 입력** 지원: 운영자가 아는 이벤트(청소/재정렬 날짜)를 지정하면
   그 시각에서 강제 분절. (계단은 대개 아는 이벤트라 이게 실무의 주 사용처)
4. 보고: 감지된 계단 후보 목록(시각, 변화율)을 R Calibrator와 α 생성 로그에
   경고로 출력. **자동 배제/삭제는 하지 않는다** — 분절 여부만 바꾼다.
5. 문턱 산정 근거를 남길 것: 캠페인 R knot 시계열에서 정상 drift의 knot 간
   변화율 분포를 먼저 재고(스크립트), 문턱은 그 분포 기반으로(예: p99.5 이상).
   매직넘버 금지 원칙.

**검증**:
- 합성 knot 시계열(완만 drift / 중간에 계단 삽입) 단위테스트 — 계단이 있으면
  분절되고 없으면 기존과 동일 출력.
- 실데이터 1일 이상으로 기존 vs 가드 적용 α 차이를 % 로 보고(무영향 확인 또는
  영향 구간 식별).
- validate_pipeline 4 PASS 유지.

## 작업 B. Etalon–기체 공선성 진단 (collinearity diagnostic)

**문제**: etalon 제거는 FFT로 주파수 f를 검출한 뒤 sin(fx)/cos(fx) 두 열을 핏
기저에 추가하는 방식(필터가 아님 — 신호 삭제 없음). 그러나 핏 창 안에서 어떤
기체 지문이 우연히 주파수 f 성분과 닮으면 두 계수가 **공선성**으로 얽혀 오차가
부풀고 농도가 흔들릴 수 있다. 이를 정량 보고하는 진단이 없다.

**위치**:
- 설계 행렬 조립: `core/doas_fit.py` (etalon sin/cos 열 추가부)
- Test Fit 팝업: `gui/app_window.py`의 `_test_fit`
- 결과 헤더 기록: `gui/worker.py` save 경로의 # 헤더

**설계 제안**:
1. `core/doas_fit.py`에 진단 함수 추가: 설계 행렬에서 (배경 다항 성분을 사영으로
   제거한) etalon 열과 각 기체 열의 **상관계수** + 기체별 **VIF**(분산팽창계수)
   계산. differential 공간에서 비교해야 의미가 있음(완만한 성분은 poly가 흡수).
2. 노출: Test Fit 팝업에 "etalon–gas corr: NO2 +0.12, CHOCHO −0.34 …" 한 줄,
   결과 파일 # 헤더에도 기록. |r| 문턱(제안 0.5) 초과 시 경고 표시 — **핏을
   막거나 값을 바꾸지 않는다**(검증≠필터).
3. 부수 확인: 현재 캠페인 시나리오(콜드 NO₂·CHOCHO·H₂O, 775–1550px)에서 실제
   값이 얼마인지 한 번 재서 기록 — 리뷰 방어의 실탄이 된다.

**검증**:
- 단위테스트: 합성 기체 지문 = 사인파(고의 공선)일 때 |r|≈1·VIF 폭발, 무관한
  지문일 때 낮음.
- 실데이터 Test Fit 1회로 수치 확인(스크립트로, GUI 클릭 아님).
- validate_pipeline 4 PASS 유지.
