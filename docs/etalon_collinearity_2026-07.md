# Etalon–기체 공선성 진단 — 실측 기록 (2026-07-16)

`core/doas_fit.py`의 `etalon_collinearity()` 진단 도입(개선작업지시_2026-07 §B)과
현 캠페인 시나리오 실측값. **진단은 보고 전용 — 핏을 막거나 값을 바꾸지 않는다**
(검증≠필터).

## 1. 배경

etalon 제거는 FFT로 검출한 주파수 f의 sin(f·x)/cos(f·x) 두 열을 핏 기저에
추가하는 방식이다 — 필터가 아니며 신호를 삭제하지 않는다. 다만 핏 창 안에서
어떤 기체 지문이 우연히 주파수 f 성분과 닮으면 두 계수가 공선성으로 얽혀
오차가 부풀 수 있다. 이를 정량 보고하는 진단이 없다는 것이 외부 리뷰
(2026-07-15)에서 반박 불가로 남은 지적이었다.

## 2. 방법

differential 공간(Chebyshev 배경 poly 사영 제거 후)에서
- r = 기체 열 ↔ etalon 2차원 부분공간(sin, cos)의 다중 상관계수 (0~1)
- VIF = 잔차공간 [기체들+etalon]에서 기체 열의 분산팽창계수(직접 회귀식 —
  상관행렬 pinv는 완전 공선에서 VIF를 과소평가하는 역설이 있어 쓰지 않음)
- VIF(no etalon) 대비 비 = etalon이 유발한 팽창

경고 문턱 |r| > 0.5 (`ETALON_CORR_WARN`). 노출: Test Fit 팝업 한 줄 +
결과 파일 `# Etalon-Gas Collinearity` 헤더.

## 3. 실측 (2026 여수 콜드 시나리오)

재현: `python tools/etalon_collinearity_probe.py`
조건: NO₂·CHOCHO·H₂O(ILS 적용 레퍼런스), 775–1550 px(438.5–475.8 nm), poly 4차,
알파 2026-05-17-001 콜드 스캔, FFT 검출 etalon f = **1.158 rad/px (주기 5.4 px)**.

| 기체 | r (실제 f) | VIF | VIF(no etalon) | etalon 유발 팽창 |
|---|---|---|---|---|
| NO₂    | 0.000 | 1.08 | 1.08 | ×1.00 |
| CHOCHO | 0.001 | 1.05 | 1.05 | ×1.00 |
| H₂O    | 0.001 | 1.03 | 1.03 | ×1.00 |

검출 밴드 전체(0.02–0.40 cycles/px = 0.126–2.513 rad/px) 스윕 최악값:

| 기체 | max r | 위치 |
|---|---|---|
| NO₂    | 0.134 | f=0.126 rad/px (주기 50 px, 밴드 하단) |
| CHOCHO | 0.150 | f=0.126 rad/px |
| H₂O    | 0.135 | f=0.126 rad/px |

## 4. 결론

- 실제 etalon 주파수(5.4 px 주기)에서 세 기체 모두 **r ≈ 0.000, 팽창 ×1.00** —
  etalon 열은 기체 지문과 사실상 직교하며 농도·오차에 영향이 없다.
- etalon 주파수가 검출 밴드 어디로 가더라도 최악 r = 0.15로 경고 문턱(0.5)의
  30% 수준. 기체 지문의 준주기 구조(NO₂ 진동 밴드 등)는 이 밴드의 사인파와
  충분히 다르다.
- 향후 시나리오(창/기체/etalon 상태 변경)에서는 Test Fit 한 줄과 결과 헤더가
  자동으로 이 값을 보고하므로, 문턱 초과 시 즉시 드러난다.

검증: `python tools/test_etalon_collinearity.py` 10 PASS (고의 공선 지문 |r|≈1·
VIF 폭발, 무관 지문 저상관, 진단 전후 핏 출력 바이트 동일).
