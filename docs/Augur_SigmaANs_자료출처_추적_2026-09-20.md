# ΣANs 자료 출처 추적 (5차, 2026-09-20)

Claude Code 가 "병합자료를 저장소 출력 트리의 어떤 핏 산물과도 연결하지 못했다"고
보고한 건에 대해, 출력 트리의 산물들과 직접 대조했다.

## 1. ★ 서로 다른 두 ΣANs 자료가 돌아다니고 있다

| 산물 | 중앙 ΣANs | 중앙 보고 불확도 | 병합 v4 와의 r (lag 0) |
|---|---|---|---|
| **병합 v4** `ans_ppb` (과학 분석용) | **+0.1477 ppb** | 0.0806 ppb | — |
| **NIER 제출본** `figure/NIER_submit/GIST_CAESAR_ANs_5min_KST_20260518_20260710.csv` (ch1−ch2, 08-03) | **+0.0756 ppb** | **0.0806 ppb** | **−0.5454** |
| `figure/ANs/alt_ch2minusch1/...` (ch2−ch1) | −0.0674 ppb | — | **+0.5029** |
| `figure/ANs/_pre_plus9/...` | — | — | −0.0831 |
| `NIER_submit/_superseded_plus8h/...` | — | — | −0.0831 |

두 가지가 동시에 보인다.

* **부호(채널 순서)가 갈린다.** 병합 v4 는 `ch2−ch1` 쪽과 **양(+0.50)**, NIER 제출본
  (`ch1−ch2`)과 **음(−0.55)** 으로 상관한다.
* **크기가 약 2배 다르다.** 병합 0.1477 vs 제출본 0.0756 ppb.
* 그런데 **보고 불확도는 두 자료가 똑같다**(0.0806 ppb). 즉 불확도 열은 같은 계보에서
  왔는데 값 열만 다른 계산이다.

±12 h 지연 주사에서도 병합 v4 는 제출본과 최대 r=+0.034(@ +11 h)밖에 안 된다 —
**단순 시간 이동으로 설명되지 않는다.**

디렉터리 이름 자체가 이력을 기록하고 있다: `_pre_plus9`, `_superseded_plus8h`,
`alt_ch2minusch1`, `_deprecated/20260723_root_transfer`, `20260723_NIER_raw`,
`20260731_NIER_corrected`. **+8 h·+9 h 시간 이동과 채널 순서 변경이 실제로 적용된
적이 있다.**

> **결론: 병합 v4 의 `ans_ppb` 는 현재 출력 트리의 어떤 산물과도 일치하지 않는다.
> 가장 가까운 친척이 `alt_ch2minusch1`(r=0.50)이고, 부호는 그쪽인데 크기는 2배다.**
> NIER 에 제출한 값과 ACP 과학 분석에 쓰는 값이 **다른 자료**다.

이건 오차예산 항목보다 큰 문제다. ΣANs 는 ACP 논문의 중심량이다.

## 2. 다행인 것 — 게이트 판정은 자료에 안 흔들린다

두 자료로 각각 게이트를 다시 세웠다(시간평균 인접차의 robust σ / √2):

| 기준 자료 | 1h \|Δ\| 중앙 | robust σ | 채널당 게이트 | I₀+R(t) 상한 0.0912 대비 |
|---|---|---|---|---|
| 병합 v4 | 0.0782 | 0.0825 | 0.0583 | **1.11배 FAIL** |
| NIER 제출본 | 0.0647 | 0.0686 | 0.0485 | **1.33배 FAIL** |

**어느 쪽을 쓰든 FAIL이고 배수만 달라진다.** 즉 §2 의 게이트 결론(“I₀+R(t) LOO 상한은
게이트를 넘고, 통과시키는 근거는 외삽”)은 출처 문제가 풀리기 전에도 유효하다.
이전 두 번의 과대추정 판정도 마찬가지로 유효하다(그때 초과 배수가 2.4~3.4배였다).

## 3. Claude Code 의 세 질문 중 두 개를 좁혔다

**Q1 (병합자료가 어느 핏 런에서 왔나)** — 출력 트리 안에는 없다. 가장 가까운 것이
`figure/ANs/alt_ch2minusch1/`(r=0.50)이지만 크기가 2배 다르므로 **다른 런**이다.
`data analysis/` 쪽 병합 스크립트나 v2(`..._20260822_v2.xlsx`)의 생성 경로를 봐야 한다.

**Q3 (ΣPNs = PNs − cold 가 맞나)** — 같은 부류의 질문이 ΣANs 에서 이미 미해결이다.
`ch1−ch2` 와 `ch2−ch1` 두 판본이 모두 저장돼 있고 **NIER 에는 `ch1−ch2` 를 제출**했다.
ΣPNs 중앙값이 음수(−0.369 ppb)로 나온 것도 같은 성격일 수 있다 — 정의가 아니라
**채널 순서**의 문제일 가능성.

**Q2 (cold·hot 같은 시계인가)** — 좁히지 못했다. 사용자 확인 필요.

## 4. 권고

1. **사용자에게 즉시 확인**: NIER 제출본(중앙 0.0756, ch1−ch2)과 과학 분석용 병합
   v4(중앙 0.1477)가 왜 다른가. 어느 쪽이 정본인가. **두 논문이 다른 숫자를 쓰면 안 된다.**
2. **②(cold 저광량 ZA 게이팅)는 그대로 진행해도 된다** — 게이트 판정이 출처에
   안 흔들리므로 측정·문턱 결정까지 막을 이유가 없다. `core/` 반영만 승인 후에.
3. ΣPNs 게이트는 Q1·Q3 가 풀린 뒤에 세운다. 지금 만들면 어느 계보 위에 세우는지
   모르는 채로 만드는 것이다.
4. 논문 관점: **이 건은 AMT 가 아니라 ACP 쪽 위험이다.** AMT 원고의 ②⑥은 운영
   산출물에서 직접 센 것이라 영향받지 않는다. ①(구조항 크기)은 게이트가 살아 있으므로
   상한 형태로는 쓸 수 있다.
