# 계기 파라미터 공간 — 실패 양상이 좌표를 옮겨도 남는가 (2026-09-23)

작업 B-3. 벤치마크는 **우리 계기 한 점**에서 만들어졌다. 그래서 "보고 σ 가 산포보다
작다"·"shift 가 비식별이다"·"창을 바꾸면 답이 바뀐다" 가 **우리 창의 성질인지 방법의
성질인지** 구분되지 않는다. 좌표를 옮겨 가며 같은 지표를 재서 답한다.

**판정은 하지 않는다.** 어느 범위가 "지속" 인지는 사용자 몫이다.

## 재현

```
python benchmark/instrument_space/run_instrument_space.py --only baseline   # 소요시간 확인
python benchmark/instrument_space/run_instrument_space.py
```

좌표당 **약 36 초**(생성 21 s + 핏 14 s), 13 좌표 **약 8 분**. 좌표별 패키지·제출본은
`work/` 에 쌓이고 gitignore 다. 요약표는 `metrics_by_coordinate.csv`, 좌표 설정은
`manifest_grid.json`.

## 좌표 설계 — OAT, 기준에서 한 번에 하나씩

| 축 | 값 | 무엇이 바뀌나 |
|---|---|---|
| `ils_scale` | 0.5 / **1.0** / 2.0 | 계기 선폭(nm). 원본 고해상 단면에서 다시 convolve |
| `window_scale` | 0.7 / **1.0** / 1.3 | 창 폭(nm). 분산 고정 → 픽셀 수 387 / 552 / 718 |
| `pixel_dispersion_scale` | 0.7 / **1.0** / 1.4 | nm/px. 창 폭 고정 → 픽셀 수 788 / 552 / 395 |
| `noise_levels` | **[1, 2]** / [0.25, 0.5, 1, 2, 4, 8] | B 군 백색잡음 수준(SNR 축 분리) |
| `poly_orders` | 2 / **3** | **스펙트럼에 넣은** 기저 차수 |
| `fit_poly_order` | 2 / **채널값(3)** / 4 / 5 / 6 | **제출자가 핏하라고 지시받는** 차수 |

⚠ **다항 차수는 두 축이다.** 처음엔 하나로 뒀다가 지표가 한 자리도 안 움직여서
갈랐다. 넣은 기저 차수를 3 → 2 로 낮춰도 `genpoly2` 가 기준과 **소수 6자리까지
같다** — 채널 차수로 핏하면 더 낮은 차수의 참 기저를 정확히 흡수하기 때문이다.
움직이는 축은 **핏 차수**(`fitpoly*`)다.

⚠ **모든 좌표를 `--rebuild-sigma` 로 만든다.** ILS 축은 원본 단면에서 다시
convolve 해야 하는데(배포본 단면은 이미 ILS 적용본이라 좁힐 수 없다), 그렇게 만든
HITRAN H₂O 는 배포본보다 피크가 **약 2.5 %** 크다. NO₂·CHOCHO 는 상관 1.00000 ·
상대 RMS 0.000 으로 일치한다. 재조립 좌표와 배포본 좌표를 섞으면 그 2.5 % 가 축에
섞이므로 **기준 좌표도 재조립**한다 — 그 대신 이 표의 `baseline` 은 배포본 261
케이스와 **같지 않다**(H₂O 만 다르다).

## 지표

전부 `doas_benchmark_v1/score.py` 가 이미 계산하는 것이다. 새 정의를 만들지 않았다.

| 열 | 군 | 뜻 |
|---|---|---|
| `b_scatter_ratio_*` | B_noise | 산포 / 보고 σ. **1.0 이면 보고가 맞다**, >1 이면 과소평가 |
| `d_unbounded_frac` | D_identifiability | 비식별 케이스를 비식별이라고 말한 비율 |
| `e_window_agreement` | E_window | 두 창 답의 최대 상대 불일치 |

⚠ **D 열은 반쪽이다.** `score.py` 는 `shift_sigma > 1 px` 또는 상자 끝 도달로
판정한다. 지시서가 요구한 **프로파일 우도 구간**은 아직 구현되지 않았으므로 이 열은
그 구현 전의 대리값이고, 표본도 5 케이스뿐이라 0.0/1.0 두 값만 나온다. 좌표 간
비교에는 쓸 수 있으나 **절대값을 원고에 싣지 말 것**.

## 아직 안 한 것

* **프로파일 우도 구간** — D 지표의 정본. 지시서 B-2 가 "그 작업이 먼저" 라고 한 항목이고
  아직 구현이 없다. 이 표의 D 열은 그때까지 대리값이다.
* **B-2 축 값 최종 확정** — 위 값은 지시서 B-1 이 적어 준 범위 그대로다. 물리적으로
  타당한 범위인지는 확인이 필요하다(특히 `ils_scale 0.5`: 실제 분광기로 도달 가능한
  선폭인가).
* **cold 채널 좌표** — 두 채널이 같은 축을 함께 움직인다. 채널별로 따로 흔들지 않았다.
