# 수용 게이트 상한 — ΣANs 는 있고 **ΣPNs 는 못 세웠다** (2026-09-20)

## 왜 만들었나

"구조항 추정치는 그것과 같은 상쇄 구조를 갖는 관측량의 변동을 넘을 수 없다" 는 게이트가
지금까지 과대추정 두 건(I₀ 1차, R(t) 3.30 %)을 잡았다. 그런데 그 게이트는 **ΣANs 에만**
있다 — 병합자료 137열을 다 뒤져도 **PNs 관련 열이 0개**다(확인 완료). cold 채널은 ΣPNs
기준선이므로, cold 에 걸린 항(저광량 ZA 블록, 긴 R(t) 간격)은 **검정할 수단이 없다.**

그래서 production 핏 결과에서 직접 만들려고 했다. **결과는 실패다.** 그 실패가 이 문서의
내용이고, 그대로 남긴다.

### ΣPNs 는 게이트 이전에 산출물이 성립하지 않는다

재구성 ΣPNs = NO2(PNs) − NO2(cold), 공통 5분 빈 8,503개:

* **중앙 −0.369 ppb** — **음수다.** 열분해 채널이 미가열 채널보다 낮게 읽는다는 뜻이라
  물리적으로 성립하지 않는다(PNs ≥ 0 이어야 한다).
* robust SD **1.42 ppb** — 신호(0.37)의 3.9배. 보고 불확도 중앙은 0.038 ppb 다.
* 시간척도 상한 0.388 ppb = 채널 NO₂ 의 **17 %**.

게이트로 쓰면 **채널당 0.275 ppb 까지 통과**시킨다 — cold 의 긴 R 간격 항(0.39~0.92 ppb)
중 일부만 겨우 걸린다. 사실상 아무것도 못 거르는 게이트다.

> **결론: cold 에 걸린 항들은 여전히 검정 수단이 없다.** ΣPNs 를 게이트로 쓰려면
> 먼저 그 산출물이 왜 음수 중앙값을 갖는지부터 풀어야 한다 — 채널 라벨, cold–hot
> 절대 보정, 두 계기의 시각 동기화 중 하나다. 셋 다 코드로 못 푼다.

# 6. 부호 문제 — 두 산출물이 **서로 다른 규약**을 쓴다

`fitting/new` 라벨은 ch1="ANs", ch2="PNs" 다. 그 라벨 기준으로:

* **병합 v4 `ans_ppb` ≈ +(ch2 − ch1)** (r +0.502, 기울기 0.570, 절편 +0.326)
* **NIER 제출본 = ch1 − ch2**

부호가 반대인 규약이다. 기울기 0.570·절편 0.326 은 병합 v4 에 epoch gain/offset 보정이
더 들어갔다는 뜻이다(raw ch2−ch1 은 중앙 −0.052·71 % 음수).

새 문제가 아니라 **미해결 H2 의 귀결**이다. 필드로그 5/27 에 현장 대조 기록이 있다 —
**"ROI1 = Green = PNs, ROI2 = Blue = ANs"** → 하드웨어로는 ch2 = ANs,
즉 **ΣANs = ch2 − ch1**(병합 v4 쪽). 반대로 물리적 거동(부호·diurnal)은 ch1 = ANs 를
가리켜 2026-08-01 잠정 작업규약이 `ANs = ch1 − ch2`(NIER 제출본 쪽)로 정해졌다.

> **데이터로는 못 정한다.** 두 규약은 부호만 뒤집힌 같은 시계열이다(상관 0.9964).
> **배관 육안확인 또는 인젝션이 최종 판정**이고, 계기 담당자 영역이다.
