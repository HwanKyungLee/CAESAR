# Augur vs QDOAS 코어 로직 직접 비교 — 결과 (2026-09-23)

사전 설계: `augur_vs_qdoas_코어비교_사전설계.md` (version dc49a43b). 코드: `h2h.py` (+ `h1_prior.py` 헬퍼 1–121행).
합성: NO₂ 1e12 + CHOCHO·H₂O, 2차 배경, squeeze 1.002, 창 444.1–470.6 nm(551 px) / 450–462 nm(250 px), poly 3.

## 한 줄 결론
**같은 모델·올바른 입력이면 Augur 코어와 QDOAS는 정확도, 오차막대, 수렴 범위에서 구별되지 않는다.
속도는 QDOAS가 스펙트럼당 약 4.6배 빠르다.** 사전에 정한 우위 기준 어느 것도 충족되지 않았다.

## E1 — 오차막대 정직성 (N = 300/조건)
| 조건 | 모델 | SD(z) Augur | SD(z) QDOAS | 비율 | 실제 산포 Augur / QDOAS | 두 프로그램 차이 산포 |
|---|---|---|---|---|---|---|
| C1 측정잡음 | etalon 끔(동일 모델) | 1.041 | 1.033 | 0.99 | 0.53 % / 0.53 % | 0.05 % |
| C2 잡음×10 | etalon 끔 | 1.047 | 1.048 | 1.00 | 5.33 % / 5.36 % | 0.48 % |
| C3 좁은 창, ×3 | etalon 끔 | 0.972 | 0.970 | 1.00 | 4.09 % / 4.11 % | 0.58 % |
| C3 | Augur 운영 모델(etalon 켬) | 1.092 | 0.970 | — | **8.27 %** / 4.11 % | 7.34 % |

- 판정: 비율 ≥ 1.10 기준 미충족 → **H1 기각.** QDOAS 보고 σ도 정직하다.
- 기전 확인: Augur 결합 σ와 shift 고정 조건부 σ의 차이 ≤ 0.5 % → 이 문제에서는 shift–NO₂ 결합이 작아
  "조건부 공분산은 σ를 과소평가한다"는 우려가 수치로 나타나지 않는다.
- 부수 발견: **Augur 코어는 etalon sin/cos 열을 끌 수 없다**(`doas_fit.py` 482행, 무조건 추가; f = 0이면 특이행렬).
  좁은 창에서는 이 두 열이 NO₂와 겹쳐 산포를 두 배로 키운다. 비교를 위해 커널 메모리 안에서만 조건부로 바꾼 사본을 썼다
  (저장소 미수정).

## E2 — 수렴 범위 (참 shift −7…+7 px × 5, 초기값 0, 경계 ±8 px)
- 크게 빗나간 경우(>1 px): **Augur 0 / QDOAS 0.** 수렴 범위 동등 → **H2 기각.**
- 사전 성공 기준(0.1 px, 1 %)은 측정 잡음에서의 shift 산포(~0.1 px)를 실패로 세는 **설계 오류**였다. 기록으로 남긴다.
- 참 shift −4…−7 px에서 QDOAS NO₂가 +0.6…+1.6 % 치우쳤다. 원인은 **QDOAS에 창 안의 픽셀만 넘긴 입력 설정**이었다.
  여유 15 px를 붙이자 −7 px에서 QDOAS −0.358 ± 0.140 %, Augur −0.373 ± 0.139 %로 일치(`h2h_E2_margin_check.csv`).
  → QDOAS 결함이 아니다(사용법 주의사항).

## E3 — 계산 시간 (기술 통계)
- QDOAS: 스펙트럼당 1.84 ms (프로세스 시작 ≈ 1 s 별도). Augur: 8.53 ms (같은 모델, 인프로세스).

## 논문에 대한 의미
1. "VarPro/해석적 자코비안이라서 더 정확하거나 더 잘 수렴한다"는 주장은 **쓸 수 없다.** 동일 모델에서 동등하다.
2. 대신 이 결과는 **강한 검증**이다: 독립 구현(QDOAS, Marquardt–SVD + 수치미분)과 잡음의 1/10 수준에서 일치.
3. 달라지는 것은 알고리즘이 아니라 **모델 선택**이다(etalon 항 하나가 좁은 창 정밀도를 두 배로 바꿈; 입력 여유 픽셀이
   큰 shift에서 1 % 편향을 만듦). 즉 결과를 좌우하는 것은 설정이지 최적화기가 아니다.
4. DOASIS(전부 비선형 LM)는 실행하지 못해 비교에 없다.
