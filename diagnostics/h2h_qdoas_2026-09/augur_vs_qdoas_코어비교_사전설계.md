# Augur vs QDOAS 코어 로직 직접 비교 — 사전 설계 (2026-09-23, 실행 전 고정)

## 목적
"Augur의 코어 로직(해석적 Golub–Pereyra VarPro + 결합 공분산)이 기존 DOAS 구현보다 답을 바꾸는
지점이 있는가"를 **같은 입력, 정답을 아는 합성 스펙트럼**으로 판정한다. 결과를 보기 전에
가설·지표·판정 기준을 여기에 고정한다. 결과를 본 뒤 기준을 바꾸지 않는다.

## 비교 대상
- **Augur**: `DoasFitter.execute_varpro_fit` (저장소 현행 코드), step limit 해제(20 px), bounds ±8 px.
- **QDOAS**: `doas_cl.exe` (conda env `qdoas`), ODF 모드(Marquardt–SVD: 선형부 SVD 소거,
  shift/stretch 도함수 수치계산), 같은 cross-section(Augur ILS 적용본), 같은 창·poly 3, bounds ±8 px.
- **DOASIS는 실행 불가** → 이번 비교에 없음(논문에 그대로 명시).
- 합성 모델: `h1_qdoas_synthetic` 파이프라인 재사용 — NO₂ 1e12 + CHOCHO·H₂O 동반,
  2차 배경, squeeze 1.002, α → I = exp(−Kα) 로 QDOAS 입력.

## 가설과 판정 기준

### E1 — 보고 오차막대가 정직한가 (σ coverage)
- 가설 H1: QDOAS의 보고 σ(SlErr)는 shift를 고정했다고 가정한 조건부 공분산이라,
  shift–NO₂ 결합이 있으면 실제 산포보다 작다. Augur 결합 공분산은 그렇지 않다.
- 조건(각 N = 300 잡음 실현):
  - C1 측정 잡음(6.16e-9 cm⁻¹), PNs 창 444.1–470.6 nm, 참 shift −1.96 px
  - C2 잡음 ×10, 같은 창
  - C3 좁은 창 450–462 nm, 잡음 ×3 (결합이 커지는 조건)
- 지표: pull z = (추정 − 참값)/σ_보고 의 표준편차 SD(z), |z|<1 비율(이상값 68.3 %), 편향.
- 기전 확인: Augur를 shift를 추정값에 고정해 다시 풀어 얻은 조건부 σ 도 함께 계산.
- 판정: SD(z)_QDOAS / SD(z)_Augur ≥ 1.10 이고 SD(z)_Augur 가 1 ± 0.1 안이면
  "Augur 오차막대가 더 정직하다"를 주장 가능. 비율 < 1.10 이면 "차이 없음"으로 보고.
  (N=300에서 SD(z)의 표준오차 ≈ 0.04)

### E2 — 수렴 범위 (초기값이 틀렸을 때)
- 가설 H2: 해석적 자코비안 VarPro는 수치미분 Marquardt–SVD보다 먼 초기값에서도 정답으로 돌아온다.
- 조건: 측정 잡음, 참 shift −6…+6 px (1 px 간격, 13개) × 잡음 5개 = 65 스펙트럼, 초기 shift 0.
- 성공: |shift 오차| < 0.1 px 이고 |NO₂ 상대오차| < 1 %.
- 판정: 성공률 100 %가 유지되는 최대 |참 shift| 가 한쪽이 ≥ 1 px 더 넓으면 "수렴 범위 우위".
  아니면 "동등".

### E3 — 계산 시간 (기술 통계만, 우위 주장 기준 없음)
- 스펙트럼당 wall time. QDOAS는 N=1과 N=전체 실행의 차로 프로세스 시작 비용 제외.

## 미리 적어 두는 한계
- 합성 = 모델이 맞는 세계. 실측 잔차 구조에서의 차이는 별도 문제.
- QDOAS ASC 출력 정밀도(상대 ~1e-4)가 E1 C1에서 지표를 흐릴 수 있음 → C1에서 σ_rel 이 1e-3보다
  작으면 C1 결론은 보류.
- 어느 결과든 보고한다. "차이 없음"도 결과다.
