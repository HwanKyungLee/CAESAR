# Cold 채널 기울기 이상의 원인 — shift 비식별성 (task 2)

작성 2026-09-19 · 대상 `diagnostics/qdoas_crossval_2026-09/`

## 요약

Cold 채널의 QDOAS 대비 회귀 기울기(README: NO₂ 1.083, CHOCHO 0.685, H₂O 1.237)는
두 코드 중 어느 쪽의 오류도 아닙니다. **Cold 창에서는 파장 shift가 데이터로 구속되지
않으며**, 두 코드가 거의 평평한 목적함수 위의 서로 다른 지점에 앉은 결과입니다.
Hot/PNs 창에서는 같은 진단이 −1.95 px에 날카로운 단일 극소점을 보여 주므로, 이것은
알고리즘 차이가 아니라 **채널 의존적 식별 가능성(identifiability)** 문제입니다.

## 1. 기록 정정 — 아카이브 QDOAS Cold 실행은 shift를 자유롭게 맞췄습니다

README의 QDOAS 설정란은 "Cold: NO2 Shift Fix(−0.5), Squeeze Fix(0.0)"로 적혀 있으나,
같은 문서의 주의사항란은 "Cold의 Shift Fix(−0.5) vs QDOAS Nonlinear"라고 적혀 서로
모순됩니다. 프로젝트 XML 두 변형(`free` = ±0.097 nm 자유, `fixm05` = −0.5 px 고정)을
재구성해 `doas_cl` 3.7.12로 다시 돌린 결과:

| 변형 | 아카이브 출력과의 상대차 중앙값 | r |
|---|---|---|
| `free` (shift 자유, ±0.097 nm) | **0.00e+00** | **1.000000** |
| `fixm05` (shift −0.5 px 고정) | 불일치 | — |

→ **아카이브 Cold 실행에서 QDOAS는 shift를 ±2.01 px 범위에서 자유롭게 맞췄습니다.**
Fix(−0.5)는 Augur 쪽 설정이며, README의 설정표 항목은 QDOAS 열에 잘못 들어가 있습니다.
주의사항란의 서술(Augur Fix vs QDOAS Nonlinear)이 맞습니다.

## 2. 같은 스펙트럼, 1 px 이상 어긋나는 shift

동일 조건(Augur도 ±2.01 px 자유, poly4)에서 같은 α를 넣었을 때:

| | 중앙값 shift | 경계(±2.01 px) 적중 |
|---|---|---|
| Augur (자유) | **−2.014 px** | 85.5 % |
| QDOAS (자유) | **−0.088 px** | 4.5 % |

수렴 문턱을 QDOAS `converge` 1e-4 → **1e-12**, max_iterations 50으로 조여도 QDOAS는
움직이지 않았습니다(중앙값 −0.065 px, 경계 적중 0.1 %). 즉 **수렴 부족이 아닙니다.**

에탈론 열도 원인이 아닙니다. Augur가 항상 추가하는 sin/cos 쌍의 주파수를
0.12 → 0.30 → 0.60 rad/px로 5배 바꿔도 shift 중앙값은 −2.014 px로 고정이고 기울기는
0.01 이내로만 변합니다.

단면도 원인이 아닙니다. `qdoas_xs/cold/*.xs`의 파장열은 Calib과, σ열은
`reference_data/wv_cal/cold/Ref_*.dat`와 일치합니다(최대 상대차는 `.xs` 기록 자릿수 수준).

## 3. 원인 — Cold 창의 목적함수가 평평합니다

프로파일된 목적함수 RSS(shift)를 −6…+6 px, 0.05 px 간격으로 직접 스캔했습니다
(현장 Cold 스펙트럼 12개, 나머지 통계는 165개).

* **RSS 변동폭이 ±4 px 구간 전체에서 중앙값 1.97 %** (p95 9.3 %)에 불과합니다.
* 12개 중 **6개는 내부 극소점이 아예 없습니다** — RSS가 스캔 경계까지 단조 감소합니다.
* 165개 기준 **77 %가 경계에서 최소**를 가집니다.
* 내부 최소를 갖는 경우에도 위치가 −4.15 … +0.80 px로 흩어집니다.
* shift = 0에서의 RSS는 최소값의 **1.0001–1.0435배**(12개 전체, 중앙값 1.0040)입니다.
  내부 극소점을 갖는 6개만 보면 1.0001–1.0033, 경계에서 최소를 갖는 6개는 1.0047–1.0435입니다.

비교 대상으로 같은 진단을 Hot/PNs 창(합성, G4)에 적용하면 −6…+6 px 전 구간에서
**극소점이 정확히 하나**이고 RSS는 최소 대비 수백 % 솟습니다(그림 a의 주황 곡선).

결론: Cold 창에서 shift는 **추정 불가능한 파라미터**입니다. Augur는 해석적 자코비안과
빡빡한 허용오차로 평평한 능선을 따라 경계까지 걸어가고, QDOAS는 shini = 0에서 출발한
Marquardt가 수치 미분으로 거의 움직이지 않습니다. 둘 다 "틀리지" 않았습니다.

## 4. 기울기가 shift 조건을 따라갑니다 (n = 5364 scans, 전 캠페인)

| 가스 | Augur Fix(−0.5) | Augur 자유 ±2.01 px | README 원본 |
|---|---|---|---|
| NO₂ | 1.019 (r 0.9736) | 0.940 (r 0.9696) | 1.083 |
| CHOCHO | 0.662 (r 0.9266) | **0.858** (r 0.9848) | 0.685 |
| H₂O | 1.178 (r 0.9858) | **1.027** (r 0.9824) | 1.237 |

조건을 맞추면 CHOCHO의 이탈이 절반으로, H₂O는 거의 해소됩니다(1.178 → 1.027,
r도 0.9266 → 0.9848로 개선). NO₂는 1.019 → 0.940으로 반대 방향으로 움직입니다 —
평평한 능선 위에서 shift를 풀어 주면 약한 동반종은 좋아지고 주 흡수체는 약간
나빠진다는, 비식별 파라미터를 자유화했을 때의 전형적 거동입니다.

## 5. 논문·운영에 대한 함의

1. **운영 설정 Fix(−0.5)는 옳은 선택이었습니다.** 식별되지 않는 파라미터를 고정한
   것이며, 사후적으로 정당화됩니다. 논문에서 방어할 수 있는 항목입니다.
2. **Cold 기울기는 "코드 간 불일치"로 인용하면 안 됩니다.** 인용한다면 조건을 맞춘
   값(0.940 / 0.858 / 1.027)과 함께 "shift 비식별성" 설명을 붙여야 합니다.
   r² 인용은 Hot 채널(NO₂ 0.9928 / 0.9998)이 안전합니다.
3. **새 진단 항목을 제안합니다.** 창마다 프로파일된 RSS(shift) 곡률을 한 번 계산해
   shift를 자유화할지 고정할지 결정하는 사전 점검. Hot/PNs는 통과, Cold는 탈락.
   G4(단일 극소점)와 짝을 이루어 "언제 비선형 파라미터를 풀어도 되는가"라는
   실무 규칙이 됩니다 — AMT 논문의 독립 기여 후보입니다.
4. **README 수정 필요**: QDOAS Cold의 shift 설정을 "자유(±0.097 nm)"로 정정.

## 남은 확인

* 세 번째 독립 보간기로 진실값을 만드는 대조 실험(task 3)은 Cold에는 적용 불가 —
  여기서는 진실값이 없고 문제가 식별 가능성 자체입니다.
* Augur가 경계까지 걸어가는 것을 막을 실무적 방법: shift에 사전분포(정규화 항)를
  두거나, 곡률 사전 점검에서 탈락하면 자동으로 고정하는 방식.
* H2(ch↔roi 매핑)는 여전히 미해결이며, Cold 결론을 바꾸지는 않습니다
  (0.62 px 차이는 위 평탄 구간 안에 묻힙니다).
